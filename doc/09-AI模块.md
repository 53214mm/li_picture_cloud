# AI 智能助手模块

## 一、模块概述

AI 模块为 LiPictureCloud 平台提供智能对话助手（PicAgent），基于 Spring AI + 阿里通义千问（qwen-max），具备工具调用、MCP 集成、图片生成、图片搜索分析等能力。前端以聊天面板形式嵌入"我的空间"页面，支持 SSE 流式输出和 Markdown 渲染。

### 核心能力

| 能力 | 实现方式 | 说明 |
|------|----------|------|
| **流式对话** | ChatClient.stream() + SSE | 逐字输出，低延迟体验 |
| **多轮记忆** | Redis ChatMemory + chatId 隔离 | 按用户+会话维度存储历史 |
| **本地工具** | @Tool 注解 + ToolCallback[] | 图片搜索/分析/保存等 10+ 工具 |
| **MCP 工具** | RefreshableMcpToolProvider | 图片生成/视频生成/图生图等 |
| **防幻觉** | 系统提示词规则 | 如实汇报工具结果、不编造 |

### 关键设计决策

| 决策 | 原因 |
|------|------|
| MCP 工具每次调用新建连接 | SSE Session 有时效限制，复用会过期 |
| 工具列表缓存 10 分钟 | 避免每次请求都连 MCP 列举工具 |
| `Hooks.enableAutomaticContextPropagation()` | Reactor 线程间传播 ThreadLocal（UserContextHolder） |
| 模型选 qwen-max | 工具调用准确度显著优于 qwen-plus |
| 系统提示词强调"如实汇报" | 防止模型编造工具调用结果 |

## 四、核心组件详解

### 4.1 PicCloudApp — AI 核心应用类

```java
@Component
public class PicCloudApp {
    static {
        // ★ Reactor 线程间传播 ThreadLocal
        reactor.core.publisher.Hooks.enableAutomaticContextPropagation();
    }

    private final ChatClient chatClient;
    private static final String SYSTEM_PROMPT = """
            你是 LiPictureCloud 图片云平台的 AI 助手，具备以下能力：

            ## 可用工具
            - 📷 图片搜索：在公开图库中按关键词搜索图片、查看图片详情、浏览最新上传
            - 📊 图片分析：分析图片格式、尺寸、宽高比，给出压缩和格式转换建议
            - 💾 保存到空间：将生成的图片保存到用户的私有空间
            - 🎨 AI 生图/视频：调用 MCP 工具生成 AI 图片或视频
            - 🔍 以图生图：提供参考图 URL 生成风格相似的图片
            - 📋 查询生成进度：通过 get_task_status 查询异步生成任务的结果

            ## 核心规则
            1. 调用工具后，必须如实汇报工具返回的结果，绝不能编造或猜测
            2. 工具调用失败时，如实告知用户失败原因，不要假装成功
            3. 用户只是闲聊打招呼时，直接回复即可，不需要调用工具
            4. 用中文回复，简洁友好，适当使用 Markdown 排版
            """;

    // 流式对话（带工具调用）
    public Flux<String> doChatStream(String message, String chatId, User currentUser) {
        UserContextHolder.set(currentUser);

        // 合并本地工具 + MCP 工具
        List<ToolCallback> combined = new ArrayList<>(Arrays.asList(allTools));
        ToolCallback[] mcpCallbacks = refreshableMcpToolProvider.getToolCallbacks();
        if (mcpCallbacks.length > 0) {
            combined.addAll(Arrays.asList(mcpCallbacks));
        }

        return chatClient.prompt()
                .user(message)
                .advisors(spec -> spec.param(ChatMemory.CONVERSATION_ID, chatId))
                .toolCallbacks(combined.toArray(new ToolCallback[0]))
                .stream().content()
                .doOnTerminate(UserContextHolder::clear)
                .doOnError(e -> UserContextHolder.clear());
    }
}
```

**工作流程：**

1. `UserContextHolder.set(currentUser)` → 设置当前用户到 ThreadLocal
2. 合并 `allTools`（本地工具） + `refreshableMcpToolProvider.getToolCallbacks()`（MCP 工具）
3. `chatClient.prompt().toolCallbacks(...).stream().content()` → Spring AI 自动处理工具调用循环
4. `doOnTerminate` / `doOnError` → 清理 ThreadLocal

### 4.2 RefreshableMcpToolProvider — MCP 工具提供者

```
工具列表获取（缓存 10 分钟）
  → 连接 mxai-mcp-server
  → client.listTools()
  → 为每个工具创建 FreshSessionMcpCallback
  → 缓存到 cachedCallbacks[]

工具调用（每次新建连接）
  → FreshSessionMcpCallback.call(toolInput)
    → 新建 McpSyncClient（解决 SSE Session 过期）
    → client.callTool(toolName, args)
    → 如果是 get_task_status 且返回 URL → autoSaveToSpace()
    → 返回结果文本
```

**为什么每次调用新建连接？**

MCP SSE 连接有时效限制。如果复用同一个 `McpSyncClient`，Session 过期后调用会报 "Invalid session ID"。每次调用新建连接虽然增加了约 500ms 的连接开销，但彻底解决了 Session 过期问题。

### 4.4 AIController — SSE 流式端点

```java
@GetMapping("/chat/stream")
public SseEmitter chatStream(@RequestParam String message,
                              @RequestParam(defaultValue = "piccloud-chat") String chatId,
                              HttpServletRequest request,
                              HttpServletResponse response) {
    // 1. 获取当前用户
    User loginUser = userService.getLoginUserEntity(request);

    // 2. CSRF 防护：Origin 校验
    String origin = request.getHeader("Origin");
    if (origin != null) {
        String host = request.getHeader("Host");
        if (host == null || !origin.endsWith(host)) {
            response.setStatus(403); return null;
        }
    }

    // 3. chatId 按用户隔离
    String scopedChatId = loginUser.getId() + ":" + chatId;

    // 4. 订阅 Flux 流，推送 SSE
    SseEmitter emitter = new SseEmitter(300000L);
    picCloudApp.doChatStream(message, scopedChatId, loginUser).subscribe(
        chunk -> emitter.send(SseEmitter.event().data(chunk)),    // 文本块
        ex -> emitter.completeWithError(new RuntimeException("AI 服务异常")), // 异常
        () -> { emitter.send(SseEmitter.event().name("done").data("")); emitter.complete(); } // 完成
    );
    return emitter;
}
```

## 五、MCP 工具集成

### 5.1 MCP 服务器配置

```yaml
# application.yaml
spring:
  ai:
    mcp:
      client:
        sse:
          connections:
            mxai-mcp-server:
              url: https://mcp.mxai.cn
              sse-endpoint: /sse
  autoconfigure:
    exclude:
      - org.springframework.ai.mcp.client.common.autoconfigure.McpToolCallbackAutoConfiguration
```

禁用 `McpToolCallbackAutoConfiguration` 后，由自定义的 `RefreshableMcpToolProvider` 接管 MCP 工具生命周期。

### 5.2 API Key 注入

```java
@Configuration
public class McpHeaderCustomizer {
    @Value("${mxai.api-key}") private String apiKey;

    @Bean
    public McpSyncHttpClientRequestCustomizer mcpAuthCustomizer() {
        return (requestBuilder, serverName, uri, method, context) -> {
            requestBuilder.header("Authorization", apiKey);
        };
    }
}
```

每次 MCP HTTP 请求都会经过此 Customizer，自动注入 `Authorization` 头。

### 5.3 MCP 工具列表

由 mxai-mcp-server 提供的工具，运行时动态获取：

| 工具 | 功能 |
|------|------|
| `generate_image` | AI 图片生成 |
| `generate_video` | AI 视频生成 |
| `get_task_status` | 查询异步任务进度/结果 |
| 其他 | 由服务端动态决定 |

### 5.4 自动保存到空间

当 `get_task_status` 返回图片 URL 时，`FreshSessionMcpCallback` 会自动调用 `autoSaveToSpace()`：

```
get_task_status 返回结果包含 http 链接
  → 提取 URL
  → 查找用户私有空间
  → pictureService.uploadPicture(url, req, user)
  → 返回 "【已自动保存到空间】"
```

### 6.5 安全渲染

```javascript
function renderMd(text) {
  let html = marked.parse(text)
  // 自动识别图片 URL 渲染为 <img>
  html = html.replace(/(https?:\/\/\S+\.(?:png|jpg|jpeg|webp|gif)(?:\?\S*)?)/gi,
    '<img src="$1" style="max-width:100%;border-radius:8px" loading="lazy" />')
  // ★ XSS 过滤
  return DOMPurify.sanitize(html)
}
```

## 八、安全措施

| 措施 | 位置 | 说明 |
|------|------|------|
| **CSRF 防护** | `AIController.java` | Origin 头校验，跨站请求直接 403 |
| **XSS 防护** | `AiAgentPanel.vue` | DOMPurify.sanitize() 过滤 Markdown 输出 |
| **用户隔离** | `AIController.java` | chatId 前缀 `userId:`，防止跨用户访问记忆 |
| **公开数据隔离** | `PictureManageTool.java` | 仅查询 `spaceId IS NULL` + `reviewStatus=1` 的图片 |
| **ThreadLocal 清理** | `PicCloudApp.java` | `doOnTerminate` + `doOnError` 双重清理 |
| **SSRF 防护** | `UrlPictureUpload.java` | DNS 解析 + 私有 IP 拦截（site-local/loopback/link-local） |
| **MCP API Key** | `McpHeaderCustomizer.java` | 每次请求动态注入 Authorization 头，不硬编码在 URL 中 |
