# LiPictureCloud — 项目总览

## 一、项目简介

LiPictureCloud 是一个基于 Spring Boot 的云端图库平台。用户可将图片上传至腾讯云对象存储（COS），系统自动提取图片的宽度、高度、格式、宽高比等元数据存入 MySQL 数据库。前端采用 Vue 3 构建，提供瑞士平面设计风格的浏览和交互体验。

### 核心能力

- 注册 / 登录 / 注销（Redis Session 共享，30 天有效期，MD5+盐值密码加密）
- **双模式图片上传**：本地文件上传 + URL 上传（模板方法模式统一流程）
- **图片处理**：COS 万象自动生成 webp 压缩图 + 256px 缩略图，三级画质分层（缩略图 → webp → 原图）
- **原图下载**：后端代理下载，权限校验（仅作者/管理员），支持 RFC 5987 中文文件名
- **图片审核**：管理员审核（通过/拒绝），普通用户上传后默认"待审核"，管理员自动过审
- **空间管理**：三级空间体系（普通/专业/旗舰），独立存储配额，上传/删除自动增减额度
- **批量抓取**：必应图片异步搜索接口抓取，Jsoup 解析 HTML，智能提取原图 URL，反爬延迟
- **多级缓存**：Caffeine 本地缓存 + Redis 分布式缓存，版本号机制保证写入后即时失效
- 图库浏览：多条件筛选（分类、格式、标签、关键词搜索）、排序、分页，URL 参数持久化
- 图片详情：全屏预览 + 元数据 + 审核状态徽标 + 编辑 + 删除 + 下载原图
- **AI 智能助手**：通义千问（qwen-max）+ Spring AI ChatClient，支持工具调用和 MCP 集成
- **图片生成**：通过 MCP 协议对接 mxai-mcp-server，支持 AI 生图/视频/以图生图
- **AI 聊天面板**：SSE 流式对话 + Markdown 渲染 + 快捷按钮，嵌入"我的空间"页面
- 基于角色的权限控制（普通用户 / 管理员），注解 + AOP 实现
- 统一响应体、全局异常处理、Jackson Long→String 序列化

## 四、代码分层架构

项目遵循 **经典三层架构 + Manager 层** 的组织方式：

```
┌─────────────────────────────────────────────────────────────────┐
│  Controller 层（对外 REST API）                                   │
│  - 接收 HTTP 请求，参数校验，调用 Service，返回统一 BaseResponse    │
├─────────────────────────────────────────────────────────────────┤
│  Service 层（核心业务逻辑）                                       │
│  - 编排业务流程：注册→加密→入库、上传→校验→COS→入库               │
│  - 继承 MyBatis-Plus ServiceImpl 获得通用 CRUD                   │
├─────────────────────────────────────────────────────────────────┤
│  Manager 层（第三方 SDK 封装）                                    │
│  - CosManager：封装腾讯云 COS 上传/下载/图片处理                   │
│  - FileManager：文件校验 + 临时文件管理 + 上传流程编排             │
├─────────────────────────────────────────────────────────────────┤
│  Mapper 层（数据访问）                                            │
│  - MyBatis-Plus BaseMapper 提供 CRUD                             │
│  - 复杂查询通过 XML 或 LambdaQueryWrapper 实现                    │
└─────────────────────────────────────────────────────────────────┘
```

**Manager 层的设计目的**：将第三方 SDK（COS）的调用细节与业务逻辑解耦。Service 层不直接操作 COSClient，而是通过 Manager 间接调用。这样切换对象存储（如换成阿里云 OSS）只需替换 Manager 实现，Service 层无需修改。

## 五、核心配置文件解读

### 5.1 application.yaml（主配置）

```yaml
spring:
  application:
    name: li-picture-cloud             # 应用名（Spring Cloud 场景下用于服务发现）
  datasource:
    username: root                     # 数据库用户名
    password: ${MYSQL_PASSWORD:123456}  # 数据库密码（环境变量覆盖，默认123456）
    url: jdbc:mysql://localhost:3306/li_picture_cloud_data
         ?useUnicode=true              # 启用 Unicode 编码
         &characterEncoding=UTF-8      # UTF-8 字符集
         &serverTimezone=Asia/Shanghai # 上海时区
    driver-class-name: com.mysql.cj.jdbc.Driver
  profiles:
    active: local                      # ★ 激活 application-local.yaml
  servlet:
    multipart:
      max-file-size: 10MB              # 文件上传全局上限 10MB
  # Redis 配置（缓存 + Session 共享）
  data:
    redis:
      database: 15                     # 使用 15 号库
      host: 127.0.0.1
      port: 6379
      timeout: 5000
      password: ${REDIS_PASSWORD:123456}  # Redis 密码（环境变量覆盖）
  session:
    store-type: redis                   # ★ Session 存入 Redis（分布式友好）
    timeout: 2592000                    # 30 天（秒）
    cookie:
      max-age: 2592000                  # 同样 30 天

server:
  port: 8124                           # 服务端口
  servlet:
    context-path: /api                 # ★ 所有 API 路径前缀 /api

mybatis-plus:
  configuration:
    map-underscore-to-camel-case: false # ★ 关闭驼峰映射（列名与字段名严格对应）
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl  # SQL 日志输出到控制台
  global-config:
    db-config:
      logic-delete-field: isDeleted    # 逻辑删除字段名
      logic-delete-value: 1            # 已删除的值
      logic-not-delete-value: 0        # 未删除的值

springdoc:
  api-docs:
    path: /v3/api-docs                 # OpenAPI JSON 端点
  swagger-ui:
    path: /swagger-ui.html             # Swagger UI 页面路径
  group-configs:
    - group: 'default'
      paths-to-match: '/**'
  packages-to-scan:
    - com.li.lipicturecloud.controller # 扫描的包
```

### 5.2 application-local.yaml（环境专属配置）

```yaml
cos:
  client:
    host: <host>
    secretId: <腾讯云 SecretId>
    secretKey: <腾讯云 SecretKey>
    region: <region>
    bucket: <bucket>
```

通过 `@ConfigurationProperties(prefix = "cos.client")` 自动绑定到 `CosClientConfig` 类的同名字段。`spring.profiles.active: local` 确保只在本地开发环境加载此文件（生产环境应使用 `application-prod.yaml`）。

## 六、启动与运行

### 6.1 后端

```bash
# 前置条件
# 1. MySQL 8.x 已启动
# 2. 创建数据库：CREATE DATABASE li_picture_cloud_data DEFAULT CHARSET utf8mb4;
# 3. 修改 application-local.yaml 中的 COS 密钥

# 启动（开发环境）
mvn spring-boot:run

# 访问 http://localhost:8124/api
# Swagger UI：http://localhost:8124/api/swagger-ui.html
```

### 6.2 前端

```bash
cd li-picture-cloud-frontend

# 安装依赖（首次）
npm install

# 开发模式（热更新）
npm run dev
# 访问 http://localhost:5173
# /api 请求自动代理到后端 :8124

# 生产构建
npm run build
# 产物输出到 dist/ 目录
```
