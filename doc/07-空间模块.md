# 空间模块

## 一、模块概述

空间模块允许用户创建私有图片空间，将图片与特定的空间关联。每个空间拥有独立的存储容量和数量上限，不同级别（普通版 / 专业版 / 旗舰版）提供不同的配额。

### 核心设计决策

1. **一对一关系**：每个用户仅能拥有一个私有空间（`synchronized` + 数据库唯一性校验）
2. **三级配额**：普通版（100张/100MB）、专业版（1000张/1GB）、旗舰版（10000张/10GB）
3. **空间隔离**：空间内图片上传到 COS 的 `space/{spaceId}/` 目录，与公共图库 `public/{userId}/` 物理隔离
4. **额度管理**：上传/删除图片时自动增减 `totalCount` 和 `totalSize`（事务保证一致性）
5. **非管理员受限**：普通用户只能创建普通版空间，管理员可创建任意级别

## 三、数据库表 — `space`

```sql
CREATE TABLE space (
    id         BIGINT PRIMARY KEY,                            -- 雪花 ID
    spaceName  VARCHAR(128),                                  -- 空间名称
    spaceLevel INT DEFAULT 0,                                 -- ★ 0=普通版 1=专业版 2=旗舰版
    maxSize    BIGINT DEFAULT 0,                              -- 图片最大总大小（字节）
    maxCount   BIGINT DEFAULT 0,                              -- 图片最大数量
    totalSize  BIGINT DEFAULT 0,                              -- 当前图片总大小（字节）
    totalCount BIGINT DEFAULT 0,                              -- 当前图片数量
    userId     BIGINT NOT NULL,                               -- 创建者 ID
    createTime DATETIME DEFAULT CURRENT_TIMESTAMP,
    editTime   DATETIME DEFAULT CURRENT_TIMESTAMP,
    updateTime DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    isDelete   TINYINT DEFAULT 0,                             -- 逻辑删除
    INDEX idx_userId (userId),
    INDEX idx_spaceName (spaceName),
    INDEX idx_spaceLevel (spaceLevel)
);
```

### Picture 表新增字段

```sql
ALTER TABLE picture
    ADD COLUMN spaceId BIGINT NULL COMMENT '空间 id（为空表示公共图库）';

CREATE INDEX idx_spaceId ON picture (spaceId);
```

`spaceId` 为 `NULL` 时表示图片属于公共图库，非 `NULL` 时指向具体空间。

## 五、创建空间 — `addSpace()`

```java
@Override
public long addSpace(SpaceAddRequest spaceAddRequest, User loginUser) {
    Space space = new Space();
    BeanUtils.copyProperties(spaceAddRequest, space);

    // 默认值
    if (StrUtil.isBlank(space.getSpaceName())) {
        space.setSpaceName("默认空间");
    }
    if (spaceAddRequest.getSpaceLevel() == null) {
        space.setSpaceLevel(SpaceLevelEnum.COMMON.getValue());  // 默认普通版
    }

    // 根据级别填充 maxSize、maxCount
    this.fillSpaceBySpaceLevel(space);
    this.validSpace(space, true);

    // ★ 权限校验：非管理员只能创建普通版空间
    if (SpaceLevelEnum.COMMON.getValue() != space.getSpaceLevel()
            && !userService.isAdmin(loginUser)) {
        throw new BusinessException(ErrorCode.NO_AUTH_ERROR, "无权限创建指定级别的空间");
    }

    // ★ 用户级锁：防止并发创建多个空间
    String lock = String.valueOf(loginUser.getId()).intern();
    synchronized (lock) {
        Long newSpaceId = transactionTemplate.execute(status -> {
            // 每个用户仅能有一个空间
            boolean exists = this.lambdaQuery()
                .eq(Space::getUserId, loginUser.getId()).exists();
            ThrowUtils.throwIf(exists, ErrorCode.OPERATION_ERROR, "每个用户仅能有一个私有空间");
            this.save(space);
            return space.getId();
        });
        return Optional.ofNullable(newSpaceId).orElse(-1L);
    }
}
```

**关键设计**：

1. `synchronized (String.valueOf(userId).intern())` — 按用户 ID 加锁，防止同一用户并发创建多个空间
2. `transactionTemplate.execute()` — 事务中检查"每个用户仅一个空间"的约束
3. `fillSpaceBySpaceLevel(space)` — 从枚举读取默认限额，但允许管理员显式覆盖

## 六、图片上传与空间关联

在 `PictureServiceImpl.uploadPicture()` 中：

```java
// 1. 校验空间是否存在
Long spaceId = pictureUploadRequest.getSpaceId();
if (spaceId != null) {
    Space space = spaceService.getById(spaceId);
    ThrowUtils.throwIf(space == null, ErrorCode.NOT_FOUND_ERROR, "空间不存在");

    if (!loginUser.getId().equals(space.getUserId())) {
        throw new BusinessException(ErrorCode.NO_AUTH_ERROR, "无权限上传到该空间");
    }
    // 校验额度
    if (space.getTotalCount() >= space.getMaxCount()) { /* 条数不足 */ }
    if (space.getTotalSize() >= space.getMaxSize()) { /* 大小不足 */ }
}

// 2. 按空间划分上传目录
String uploadPathPrefix;
if (spaceId == null) {
    uploadPathPrefix = String.format("public/%s", loginUser.getId());  // 公共图库
} else {
    uploadPathPrefix = String.format("space/%s", spaceId);             // 私有空间
}

// 3. 事务中更新空间额度
picture.setSpaceId(spaceId);
transactionTemplate.execute(status -> {
    this.saveOrUpdate(picture);
    if (finalSpaceId != null) {
        // 增加空间已用量
        spaceService.lambdaUpdate()
            .eq(Space::getId, finalSpaceId)
            .setSql("totalSize = totalSize + " + picture.getPicSize())
            .setSql("totalCount = totalCount + 1")
            .update();
    }
    return picture;
});
```

## 七、图片删除与额度释放

```java
@Override
public void deletePicture(long pictureId, User loginUser) {
    Picture oldPicture = this.getById(pictureId);
    checkPictureAuth(loginUser, oldPicture);  // 权限校验

    transactionTemplate.execute(status -> {
        this.removeById(pictureId);
        // ★ 仅私有空间的图片需要释放额度
        Long pictureSpaceId = oldPicture.getSpaceId();
        if (pictureSpaceId != null) {
            spaceService.lambdaUpdate()
                .eq(Space::getId, pictureSpaceId)
                .setSql("totalSize = totalSize - " + oldPicture.getPicSize())
                .setSql("totalCount = totalCount - 1")
                .update();
        }
        return true;
    });
}
```

## 八、空间权限校验 — `checkPictureAuth()`

```java
public void checkPictureAuth(User loginUser, Picture picture) {
    Long spaceId = picture.getSpaceId();
    if (spaceId == null) {
        // 公共图库：仅本人或管理员可操作
        if (!picture.getUserId().equals(loginUser.getId())
                && !userService.isAdmin(loginUser)) {
            throw new BusinessException(ErrorCode.NO_AUTH_ERROR);
        }
    } else {
        // 私有空间：仅空间所有者可操作
        if (!picture.getUserId().equals(loginUser.getId())) {
            throw new BusinessException(ErrorCode.NO_AUTH_ERROR);
        }
    }
}
```

权限规则：
- **公共图库图片**（`spaceId` 为空）：图片作者 或 管理员 可操作
- **私有空间图片**（`spaceId` 非空）：仅空间所有者（= 图片上传者）可操作，管理员也无权

## 九、图片列表查询中的空间逻辑

```java
// PictureController.listPictureVOByPage()
Long spaceId = pictureQueryRequest.getSpaceId();
if (spaceId == null) {
    // 公开图库：只展示已过审图片 + 限定 spaceId IS NULL
    pictureQueryRequest.setReviewStatus(PictureReviewStatusEnum.PASS.getValue());
    pictureQueryRequest.setNullSpaceId(true);
} else {
    // 私有空间：校验空间权限
    Space space = spaceService.getById(spaceId);
    ThrowUtils.throwIf(space == null, ErrorCode.NOT_FOUND_ERROR, "空间不存在");
    if (!loginUser.getId().equals(space.getUserId())) {
        throw new BusinessException(ErrorCode.NO_AUTH_ERROR, "没有空间权限");
    }
}
```

查询时 `nullSpaceId = true` 会在 SQL 中追加 `WHERE spaceId IS NULL`，确保公开图库只返回不属于任何空间的图片。

## 十、API 接口参考

### 10.1 创建空间

```
POST /space/add
需要登录

请求体：
{
  "spaceName": "我的空间",      // 可选，默认"默认空间"
  "spaceLevel": 0               // 可选，0=普通版 1=专业版 2=旗舰版（默认0）
}

成功响应：
{ "code": 0, "data": 1823456789012345678 }  // 空间 ID

可能错误：
- 40101: 无权限创建指定级别的空间（非管理员选非普通版）
- 50001: 每个用户仅能有一个私有空间
```

### 10.2 删除空间

```
POST /space/delete
需要登录（仅本人或管理员）

请求体：
{ "id": 1823456789012345678 }

说明：仅删除空间记录，不删除空间内的图片
```

### 10.3 编辑空间（用户）

```
POST /space/edit
需要登录（仅本人或管理员可编辑名称）

请求体：
{ "id": 1823456789012345678, "spaceName": "新名称" }

说明：仅支持修改名称，不能修改级别和限额
```

### 10.4 更新空间（管理员）

```
POST /space/update
需要 admin 角色

请求体：
{
  "id": 1823456789012345678,
  "spaceName": "新名称",          // 可选
  "spaceLevel": 1,                // 可选，级别变化时自动填充默认限额
  "maxSize": 2147483648,          // 可选，覆盖级别默认值
  "maxCount": 500                 // 可选，覆盖级别默认值

说明：仅更新非 null 字段，null 字段保留数据库原值
```

## 十一、前端页面架构

### 11.1 路由设计

| 路由 | 页面 | 说明 |
|------|------|------|
| `/spaces` | `SpaceManageView` | 空间管理列表（所有用户可见，可浏览全部空间） |
| `/space/create` | `SpaceCreateView` | 创建空间（级别卡片 + 表单） |
| `/space/my` | `MySpaceView` | 我的空间概览（用量统计 + 快捷入口） |
| `/space/:id` | `SpaceDetailView` | 空间详情（图片网格 + 上传面板 + 编辑/删除） |

### 11.2 可复用组件 — PictureList

`components/PictureList.vue` 封装了图片网格的通用逻辑：

- **Props**：`pictures`、`loading`、`total`、`current`、`pageSize`、`categoryList`、`emptyText`、`showToolbar`、`showActions`
- **插槽**：`#toolbar-actions`（工具栏右侧操作）、`#actions="{ picture }"`（卡片快捷操作按钮）
- **事件**：`@search`、`@filter-change`、`@page-change`
- 内置搜索框、分类/格式/排序筛选、分页（含跳页输入框）

### 11.3 SpaceManageView — 空间管理列表

- 顶栏：「我的空间」+「创建空间」按钮
- 空间卡片：名称（可点击进入详情）、级别徽标、「我的」标记、容量/数量进度条
- 操作按钮：查看图片、编辑（本人或管理员）、删除（本人或管理员）
- 编辑弹窗：用户可改名，管理员可改级别 + 覆盖限额
- 分页浏览

### 11.4 SpaceCreateView — 创建空间

- 专用路由页面，展示三个级别卡片（普通版/专业版/旗舰版）及配额详情
- 点击卡片选择级别（高亮 + ✓ 标记）
- 非管理员选非普通版时显示提示，自动回落为普通版
- 空间名称输入（默认「我的空间」）
- 创建成功后跳转到空间详情页

### 11.5 MySpaceView — 我的空间

- 有空间时：展示空间名称 + 级别徽标 + 用量概览（图片数/容量/综合使用率 三卡片）+ 快捷操作（上传/浏览/改名）
- 无空间时：引导创建页面
- 修改名称弹窗

### 11.6 SpaceDetailView — 空间详情

- 空间信息头（名称、级别、进度条）
- **上传面板**（空间所有者可见）：标签页切换文件/URL 上传，自动关联当前空间
- **PictureList 组件**：展示空间内图片，带搜索筛选
- **快捷操作**（空间所有者可见）：悬停显示编辑/删除按钮
- **编辑弹窗**：名称、简介、分类、标签
- **删除确认**：删除后自动刷新列表和空间用量
- 权限控制：仅空间所有者可上传/编辑/删除空间内图片

### 11.7 上传页面集成

`PictureUploadView`：
- 加载用户空间列表，下拉框选择上传目标空间
- URL 参数 `?spaceId=xxx` 可预选空间（从 MySpaceView 跳转）
- 上传时将 `spaceId` 作为参数传递给后端
