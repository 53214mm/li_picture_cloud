# 图片分享与批量管理

## 一、模块概述

本模块包含三个独立功能：**以图搜图**（Bing 反向图片搜索）、**图片分享**（链接复制 + 二维码）、**图片批量管理**（批量设置分类/标签/名称）。

---

## 二、以图搜图（Bing 反向图片搜索）

### 2.1 架构

```
用户输入图片 URL
  → POST /api/picture/search/image
  → ImageSearchApiFacade.searchByImage()
    → GetImagePageUrlApi.searchByImage()
      → Jsoup GET bing.com/images/search?q=imgurl:{url}
      → 解析 HTML 中的 a.iusc 元素（m 属性 JSON）
      → 提取 murl（原图直链）+ turl（缩略图）
    → 返回 List<ImageSearchResult>
  → 前端展示缩略图网格
```

### 2.2 后端文件

| 文件 | 路径 | 角色 |
|------|------|------|
| `ImageSearchApiFacade` | `api/imagesearch/ImageSearchApiFacade.java` | 门面（`@Component`，单步调用） |
| `GetImagePageUrlApi` | `api/imagesearch/sub/GetImagePageUrlApi.java` | 核心：Jsoup 请求 + HTML 解析 |
| `ImageSearchResult` | `api/imagesearch/model/ImageSearchResult.java` | 结果 DTO（`thumbUrl` + `fromUrl`） |
| `GetImageFirstUrlApi` | `api/imagesearch/sub/GetImageFirstUrlApi.java` | [已废弃] 百度方案遗留 |
| `GetImageListApi` | `api/imagesearch/sub/GetImageListApi.java` | [已废弃] 百度方案遗留 |

### 2.3 关键代码

```java
// GetImagePageUrlApi.searchByImage()
String searchUrl = "https://www.bing.com/images/search?view=detailv2&iss=sbi&form=SBIIRP"
        + "&q=imgurl:" + URLUtil.encode(imageUrl);

Document doc = Jsoup.connect(searchUrl)
        .header("User-Agent", "Mozilla/5.0 ... Chrome/120.0.0.0 ...")
        .timeout(15000)
        .get();

// 解析 iusc 卡片的 m 属性 JSON
for (Element card : doc.select("a.iusc")) {
    JSONObject mJson = JSONUtil.parseObj(card.attr("m"));
    String murl = mJson.getStr("murl");   // 原图
    String turl = mJson.getStr("turl");   // 缩略图
    // 校验 URL 协议（防 XSS）
    if (isSafeUrl(murl)) result.setFromUrl(murl);
}
```

### 2.4 安全措施

| 措施 | 位置 |
|------|------|
| Controller 入口校验 URL 必须 `http/https` 开头 | `PictureController.java:421` |
| `isSafeUrl()` 过滤 `javascript:` 等危险协议 | `GetImagePageUrlApi.java` |
| 前端 `<a target="_blank">` 加 `rel="noopener noreferrer"` | `PictureManageView.vue` |

### 2.5 API 端点

```
POST /picture/search/image
需要登录

请求体：{ "fileUrl": "https://example.com/image.jpg" }
成功响应：{
  "code": 0,
  "data": [
    { "thumbUrl": "https://tse1.mm.bing.net/th?id=...", "fromUrl": "https://source.com/img.jpg" }
  ]
}
```

### 2.6 前端集成

在 `PictureManageView`（图片审核管理页）顶部的可折叠面板中：
- 输入框粘贴图片 URL → 点击「搜索」
- 结果以缩略图网格展示
- 每张结果有两个按钮：「上传」（通过 URL 上传到系统）、「来源」（新标签打开原页面）

### 3.2 Props

| Prop | 类型 | 说明 |

| `pictureId` | `String / Number` | 图片 ID，用于生成分享链接 |
| `title` | `String` | 图片名称（弹窗中显示） |
| `imageUrl` | `String` | 预览用的图片 URL |
| `thumbnailUrl` | `String` | 缩略图 URL |

### 3.3 Events

| Event | 说明 |
|-------|------|
| `@close` | 关闭弹窗 |

### 3.4 功能

| 功能 | 实现方式 |
|------|----------|

## 四、图片批量管理

### 4.1 功能概述

空间所有者可批量修改空间内图片的**分类**、**标签**和**名称**（支持序号命名规则）。

### 4.2 后端实现

```java
// PictureServiceImpl.editPictureByBatch()
@Override
@Transactional(rollbackFor = Exception.class)
public void editPictureByBatch(PictureEditByBatchRequest request, User loginUser) {
    // 1. 校验参数 + 空间权限
    // 2. 查询指定图片列表
    List<Picture> pictureList = this.lambdaQuery()
            .eq(Picture::getSpaceId, spaceId)
            .in(Picture::getId, pictureIdList)
            .list();
    // 3. 批量设置分类、标签、名称
    for (Picture picture : pictureList) {
        if (StrUtil.isNotBlank(category)) picture.setCategory(category);
        if (CollUtil.isNotEmpty(tags)) picture.setTags(JSONUtil.toJsonStr(tags));
        if (StrUtil.isNotBlank(nameRule)) {
            picture.setName(nameRule.replaceAll("\\{序号}", String.valueOf(count++)));
        }
        picture.setEditTime(new Date());
    }
    // 4. 一次性批量更新
    this.updateBatchById(pictureList);
}
```

### 4.3 API 端点

```
POST /picture/edit/batch
需要登录（空间所有者）

请求体：
{
  "pictureIdList": ["2077324386333974529", "2077323580343934978"],
  "spaceId": "2077316097206501378",
  "category": "风景",                   // 可选
  "tags": ["城市", "夜景"],            // 可选
  "nameRule": "图片{序号}"             // 可选，{序号} 自动替换为 1, 2, 3...
}
成功响应：{ "code": 0, "data": true }
```

### 4.4 命名规则

`nameRule` 中的 `{序号}` 会被自动替换为递增数字（从 1 开始）：

| nameRule | 结果 |
|----------|------|
| `图片{序号}` | 图片1, 图片2, 图片3... |
| `风景-{序号}` | 风景-1, 风景-2, 风景-3... |

### 4.5 前端交互流程

1. 空间详情页点击 **「批量管理」** 进入选择模式
2. 每张图片左上角出现复选框，顶部显示「全选当前页」
3. 勾选图片后，顶部出现批量工具栏：
   - 已选计数 `已选 N 张`
   - 分类输入框
   - 标签输入框（逗号分隔）
   - 命名规则输入框（`图片{序号}`）
   - 「应用」按钮执行批量更新
   - 「取消选择」清空勾选
4. 应用后自动刷新列表，清除选择
5. 退出批量模式关闭复选框
