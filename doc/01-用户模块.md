# 用户模块

## 一、模块概述

用户模块是整个系统的认证入口，负责用户身份注册、登录/注销、Session 管理以及管理端的用户 CRUD 操作。

### 设计要点

- **密码安全**：明文密码与固定盐值拼接后做 MD5 摘要，数据库存储密文
- **会话管理**：登录成功后将用户脱敏信息（UserVO）存入 HttpSession，后续请求通过读取 Session 判断登录态
- **权限控制**：通过自定义注解 `@AuthCheck` + AOP 切面实现方法级权限校验
- **数据脱敏**：对外接口统一返回 UserVO（不含密码字段），仅管理员 `GET /user/get` 返回完整 User 实体

## 三、数据库表 — `user`

```sql
CREATE TABLE user (
    id           BIGINT PRIMARY KEY,              -- 雪花算法生成，19位十进制数
    userAccount  VARCHAR(256) NOT NULL UNIQUE,    -- 登录账号
    userPassword VARCHAR(512) NOT NULL,           -- MD5(明文 + 盐值) 密文
    userName     VARCHAR(256),                    -- 显示昵称（默认取 userAccount）
    userAvatar   VARCHAR(1024),                   -- 头像图片 URL
    userProfile  VARCHAR(512),                    -- 个人简介
    userRole     VARCHAR(64) DEFAULT 'user',      -- 角色：user（默认）/ admin
    editTime     DATETIME,                        -- 最后编辑时间
    createTime   DATETIME,                        -- 注册时间
    updateTime   DATETIME,                        -- MyBatis-Plus 自动填充
    isDelete     TINYINT DEFAULT 0               -- 逻辑删除：0=正常, 1=已删除
);
```

### 实体类 `User.java` 对应关系

```java
@TableName(value = "user")              // 映射到 user 表
@Data                                   // Lombok：自动生成 getter/setter/toString/equals/hashCode
public class User {

    @TableId(type = IdType.ASSIGN_ID)   // ★ 雪花算法自动生成主键
    private Long id;

    private String userAccount;
    private String userPassword;        // ★ 注意：包含密文，接口返回时需脱敏
    private String userName;
    private String userAvatar;
    private String userProfile;
    private String userRole;

    private Date editTime;
    private Date createTime;
    private Date updateTime;

    @TableLogic                         // ★ 逻辑删除标记
    private Integer isDelete;           //    查询/删除自动追加 WHERE isDelete=0
}
```

| 注解 | 作用 |
|------|------|
| `@TableName("user")` | 指定对应的数据库表名 |
| `@TableId(type = IdType.ASSIGN_ID)` | 使用雪花算法生成分布式唯一 ID（19 位 Long） |
| `@TableLogic` | 标记逻辑删除字段，MyBatis-Plus 的 `deleteById` 会转为 `UPDATE SET isDelete=1`，`selectList` 自动追加 `WHERE isDelete=0` |
| `@Data` | Lombok 注解，编译期生成 getter/setter/toString/equals/hashCode |

### 为什么用雪花算法而不是自增 ID？

1. **分布式友好**：雪花 ID 全局唯一，未来分库分表时不会冲突
2. **安全性**：自增 ID 会暴露用户数量、增长速度等信息
3. **前端兼容**：19 位 Long 超出 JS 安全整数范围（2^53-1），通过 Jackson 配置序列化为 String

## 四、角色枚举 — `UserRoleEnum`

```java
@Getter
public enum UserRoleEnum {
    USER("用户", "user"),        // 普通用户
    ADMIN("管理员", "admin");     // 管理员

    private final String text;   // 中文描述
    private final String value;  // 数据库存储值

    /**
     * 根据 value 查找枚举（大小写敏感）
     * 找不到时返回 null，调用方自行处理
     */
    public static UserRoleEnum getEnumByValue(String value) {
        if (value == null) return null;
        for (UserRoleEnum e : values()) {
            if (e.value.equals(value)) return e;
        }
        return null;
    }
}
```

## 五、常量定义 — `UserConstant`

```java
public class UserConstant {
    public static final String SESSION_USER_KEY = "loginUser";  // Session 中存储用户信息的 key
    public static final String DEFAULT_ROLE = "user";            // 注册时的默认角色
    public static final String ADMIN_ROLE = "admin";             // 管理员角色字符串
    public static final String SALT = "liPictureCloud2026";      // ★ 密码加密盐值
}
```

盐值的作用：即使两个用户的明文密码完全相同，由于使用了与系统绑定的固定盐值，数据库中的密文也不容易被彩虹表逆向破解。生产环境建议改用随机盐值 + BCrypt/Argon2。

## 六、密码加密流程

```
明文密码（用户输入） + 固定盐值 → MD5 摘要 → 存入数据库

示例：
  明文：password123
  盐值：liPictureCloud2026
  拼接：password123liPictureCloud2026
  MD5：  e10adc3949ba59abbe56e057f20f883e  （存入 userPassword 字段）
```

```java
// UserServiceImpl.java 中的加密代码（注册和登录共用同一套规则）
String encryptedPassword = DigestUtil.md5Hex(userPassword + UserConstant.SALT);
```

`DigestUtil.md5Hex()` 是 Hutool 提供的 MD5 工具方法，返回 32 位十六进制小写字符串。

## 七、用户注册 — `userRegister()` 源码逐段讲解

```java
@Override
public long userRegister(UserRegisterRequest userRegisterRequest) {
```

### Step 1 — 提取参数并做非空校验

```java
    String userAccount = userRegisterRequest.getUserAccount();
    String userPassword = userRegisterRequest.getUserPassword();
    String checkPassword = userRegisterRequest.getCheckPassword();

    if (StrUtil.isBlank(userAccount)) {      // isBlank：null / "" / "  " 均拦截
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "账号不能为空");
    }
    if (StrUtil.isBlank(userPassword)) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "密码不能为空");
    }
    if (StrUtil.isBlank(checkPassword)) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "确认密码不能为空");
    }
```

### Step 2 — 长度下限校验

```java
    if (userAccount.length() < MIN_ACCOUNT_LENGTH) {    // MIN_ACCOUNT_LENGTH = 4
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "账号长度不能小于4位");
    }
    if (userPassword.length() < MIN_PASSWORD_LENGTH) {  // MIN_PASSWORD_LENGTH = 8
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "密码长度不能小于8位");
    }
```

### Step 3 — 两次密码一致性校验

```java
    if (!userPassword.equals(checkPassword)) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "两次输入的密码不一致");
    }
```

### Step 4 — 账号唯一性校验

```java
    LambdaQueryWrapper<User> queryWrapper = new LambdaQueryWrapper<>();
    queryWrapper.eq(User::getUserAccount, userAccount);  // Lambda 引用防止字段名拼写错误
    long count = this.count(queryWrapper);
    if (count > 0) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "该账号已被注册");
    }
```

`LambdaQueryWrapper` 是 MyBatis-Plus 提供的类型安全查询构造器。`User::getUserAccount` 是 Java 方法引用，编译期就能检查字段名是否正确，比字符串 `"user_account"` 更安全。

### Step 5 — 密码加密

```java
    String encryptedPassword = DigestUtil.md5Hex(userPassword + UserConstant.SALT);
```

### Step 6 — 构造实体并入库

```java
    User user = new User();
    user.setUserAccount(userAccount);
    user.setUserPassword(encryptedPassword);
    user.setUserName(userAccount);              // 默认昵称 = 账号
    user.setUserRole(UserConstant.DEFAULT_ROLE); // 默认角色 = "user"

    boolean saved = this.save(user);             // MyBatis-Plus 的 save 方法
    if (!saved) {
        throw new BusinessException(ErrorCode.SYSTEM_ERROR, "注册失败，请稍后重试");
    }
    return user.getId();                         // 返回雪花 ID
}
```

## 八、用户登录 — `userLogin()` 源码逐段讲解

```java
@Override
public UserVO userLogin(UserLoginRequest userLoginRequest, HttpServletRequest request) {
```

### Step 1 — 参数非空校验

```java
    String userAccount = userLoginRequest.getUserAccount();
    String userPassword = userLoginRequest.getUserPassword();

    if (StrUtil.isBlank(userAccount)) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "账号不能为空");
    }
    if (StrUtil.isBlank(userPassword)) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "密码不能为空");
    }
```

### Step 2 — 查询用户

```java
    LambdaQueryWrapper<User> queryWrapper = new LambdaQueryWrapper<>();
    queryWrapper.eq(User::getUserAccount, userAccount);
    User user = this.getOne(queryWrapper);          // getOne：查询单条记录
    if (user == null) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "账号或密码错误");
    }
```

### Step 3 — 密码验证

```java
    String encryptedPassword = DigestUtil.md5Hex(userPassword + UserConstant.SALT);
    if (!encryptedPassword.equals(user.getUserPassword())) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "账号或密码错误");
    }
```

**安全设计**：账号不存在和密码错误返回相同的错误信息（"账号或密码错误"），防止攻击者通过差异化的错误信息枚举有效账号。

### Step 4 — 写入 Session

```java
    UserVO userVO = convertToVO(user);              // 实体 → 脱敏 VO
    HttpSession session = request.getSession();      // 获取或创建 Session
    session.setAttribute(UserConstant.SESSION_USER_KEY, userVO);  // key = "loginUser"
    return userVO;
}
```

**关键点**：Session 中存入的是 `UserVO`（不含密码），而不是 `User` 实体。`getLoginUser()` 方法也返回 `UserVO`，保证类型一致，避免 `ClassCastException`。

## 九、User 实体 → UserVO 转换

```java
private UserVO convertToVO(User user) {
    UserVO userVO = new UserVO();
    BeanUtil.copyProperties(user, userVO);      // Hutool BeanUtil 拷贝同名同类型属性
    return userVO;                               // userPassword 在 UserVO 中无对应字段，自动忽略
}
```

`UserVO` 对比 `User`：

| 字段 | User 实体 | UserVO 视图 |
|------|-----------|-------------|
| `userPassword` | ✅ 包含（MD5 密文） | ❌ 不存在（脱敏） |
| `isDelete` | ✅ 包含 | ❌ 不存在 |
| `updateTime` | ✅ 包含 | ❌ 不存在 |
| 其他字段 | ✅ | ✅ |

## 十、获取当前登录用户 — `getLoginUser()`

```java
@Override
public UserVO getLoginUser(HttpServletRequest request) {
    HttpSession session = request.getSession(false);    // false：不自动创建 Session
    if (session == null) {
        throw new BusinessException(ErrorCode.NOT_LOGIN_ERROR);
    }

    Object userObj = session.getAttribute(UserConstant.SESSION_USER_KEY);
    if (userObj == null) {
        throw new BusinessException(ErrorCode.NOT_LOGIN_ERROR);
    }

    return (UserVO) userObj;                           // ★ 强转为 UserVO（登录时存入的类型）
}
```

@Override
public boolean userLogout(HttpServletRequest request) {
    HttpSession session = request.getSession(false);   // 获取已有 Session，不创建新的
    if (session != null) {
        session.removeAttribute(UserConstant.SESSION_USER_KEY);  // 移除登录标记

## 十二、管理员用户管理

### 12.1 创建用户 — `addUser()`

管理员创建用户的流程与注册类似，主要区别：

- **不需要确认密码**：管理员直接设置密码
- **可指定角色**：传入 `userRole` 需在枚举范围内，否则默认 `"user"`
- **可填个人信息**：昵称、头像、简介可选，昵称默认取账号名

```java
// 角色校验
String role = userAddRequest.getUserRole();
user.setUserRole(UserRoleEnum.getEnumByValue(role) != null ? role : UserConstant.DEFAULT_ROLE);
```

### 12.2 更新用户 — `updateUser()`

- 仅更新非 null 字段（昵称、头像、简介、角色），null 字段保留原值
- **不更新密码**：密码修改需单独接口
- 角色值需在 `UserRoleEnum` 中有效

```java
// 仅覆盖非 null 的字段
if (StrUtil.isNotBlank(userUpdateRequest.getUserName())) {
    user.setUserName(userUpdateRequest.getUserName());
}
if (StrUtil.isNotBlank(userUpdateRequest.getUserRole())) {
    String role = userUpdateRequest.getUserRole();
    if (UserRoleEnum.getEnumByValue(role) == null) {
        throw new BusinessException(ErrorCode.PARAMS_ERROR, "无效的用户角色");
    }
    user.setUserRole(role);
}
```

### 12.3 分页查询 — `listUserByPage()`

```java
@Override
public IPage<UserVO> listUserByPage(UserQueryRequest userQueryRequest) {
    // 构建分页对象
    Page<User> page = new Page<>(userQueryRequest.getCurrent(), userQueryRequest.getPageSize());

    // 构建条件：ID 精确、账号/昵称 模糊、角色 精确
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(userQueryRequest.getId() != null, User::getId, userQueryRequest.getId());
    wrapper.like(StrUtil.isNotBlank(userQueryRequest.getUserAccount()), User::getUserAccount, userQueryRequest.getUserAccount());
    wrapper.like(StrUtil.isNotBlank(userQueryRequest.getUserName()), User::getUserName, userQueryRequest.getUserName());
    wrapper.eq(StrUtil.isNotBlank(userQueryRequest.getUserRole()), User::getUserRole, userQueryRequest.getUserRole());
    wrapper.orderByDesc(User::getCreateTime);

    // 执行查询
    IPage<User> userPage = this.page(page, wrapper);

    // ★ 转换为 UserVO 列表（脱敏）
    List<UserVO> voList = userPage.getRecords().stream()
            .map(this::convertToVO)
            .collect(Collectors.toList());

    // 构造 VO 分页结果
    Page<UserVO> voPage = new Page<>(userPage.getCurrent(), userPage.getSize(), userPage.getTotal());
    voPage.setRecords(voList);
    return voPage;
}
```

`LambdaQueryWrapper.eq(condition, field, value)` 的第一个参数为 boolean 条件，当 condition 为 false 时自动忽略该条件。这是 MyBatis-Plus 的"条件构造器"模式，避免了大量的 if-else 判断。

## 十三、权限控制 — `@AuthCheck` + AOP

### 13.1 注解定义

```java
@Target(ElementType.METHOD)         // 只能标注在方法上
@Retention(RetentionPolicy.RUNTIME) // 运行时保留（AOP 需要反射读取）
public @interface AuthCheck {
    String mustRole() default "";   // 需要的角色值，"admin" / "user" / ""（仅需登录）
}
```

### 13.2 AOP 切面实现

```java
@Aspect
@Component
public class AuthInterceptor {

    @Around("@annotation(authCheck)")   // ★ 环绕通知：拦截所有标注了 @AuthCheck 的方法
    public Object doInterceptor(ProceedingJoinPoint joinPoint, AuthCheck authCheck) throws Throwable {
        String mustRole = authCheck.mustRole();

        // 从当前请求上下文获取 HttpServletRequest
        RequestAttributes requestAttributes = RequestContextHolder.currentRequestAttributes();
        HttpServletRequest request = ((ServletRequestAttributes) requestAttributes).getRequest();

        // 获取当前登录用户
        UserVO loginUser = userService.getLoginUser(request);
        UserRoleEnum mustRoleEnum = UserRoleEnum.getEnumByValue(mustRole);

        // mustRole 为空 → 只要求登录即可，放行
        if (mustRoleEnum == null) {
            return joinPoint.proceed();
        }

        // 获取当前用户的角色
        UserRoleEnum userRoleEnum = UserRoleEnum.getEnumByValue(loginUser.getUserRole());
        if (userRoleEnum == null) {
            throw new BusinessException(ErrorCode.NO_AUTH_ERROR);
        }

        // 要求 admin 但用户不是 admin → 拒绝
        if (UserRoleEnum.ADMIN.equals(mustRoleEnum) && !UserRoleEnum.ADMIN.equals(userRoleEnum)) {
            throw new BusinessException(ErrorCode.NO_AUTH_ERROR);
        }

        // 通过校验，执行目标方法
        return joinPoint.proceed();
    }
}
```

### 13.3 使用示例

```java
// 需要管理员权限
@AuthCheck(mustRole = "admin")
@PostMapping("/add")
public BaseResponse<Long> addUser(...) { ... }

// 只需要登录（mustRole 默认空字符串）
@AuthCheck
@PostMapping("/delete")
public BaseResponse<Boolean> deletePicture(...) { ... }
```

当 `mustRole = ""` 时，`getEnumByValue("")` 返回 null，切面直接放行——此时注解仅起到"必须登录"的作用（因为 `getLoginUser()` 若检测到未登录会抛出异常）。
