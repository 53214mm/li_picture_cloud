# 前端文档

## 一、概述

前端基于 **Vue 3 Composition API**（`<script setup>` 语法）+ **Vite** 构建。设计风格采用 **瑞士平面设计（Swiss Graphic Design）**——大量留白、无衬线字体 Inter、黑/白为主色辅以红/黄/蓝点缀、强调网格对齐和信息层级。

## 五、根组件 — `App.vue`

```vue
<template>
  <div id="app-root">
    <NavBar />
    <main>
      <router-view v-slot="{ Component }">
        <transition name="page" mode="out-in">
          <component :is="Component" />
        </transition>
      </router-view>
    </main>
  </div>
</template>

<script setup>
import NavBar from '@/components/NavBar.vue'
import { useUserStore } from '@/stores/user'

const userStore = useUserStore()
userStore.fetchCurrentUser()          // ★ 页面初始化时尝试获取登录用户
</script>
```

**工作流程**：
1. 应用启动 → `createApp` → `mount`
2. `App.vue` 渲染 → `<script setup>` 中调用 `fetchCurrentUser()`
3. `fetchCurrentUser()` 调用 `GET /user/current`
   - 成功 → `currentUser` 有值 → `isLoggedIn = true` → 导航栏显示用户信息和"登出"
   - 失败（Session 不存在） → `currentUser = null` → 导航栏显示"登录"/"注册"

`<transition name="page">` 提供路由切换时的淡入淡出效果（`.page-enter-active` / `.page-leave-active`）。

## 七、路由配置 — `router/index.js`

```javascript
import { createRouter, createWebHistory } from 'vue-router'
import HomeView from '@/views/HomeView.vue'

const routes = [
  { path: '/',              name: 'home',            component: HomeView },                           // 立即加载
  { path: '/login',         name: 'login',           component: () => import('@/views/LoginView.vue') },
  { path: '/register',      name: 'register',        component: () => import('@/views/RegisterView.vue') },
  { path: '/gallery',       name: 'gallery',         component: () => import('@/views/GalleryView.vue') },
  { path: '/picture/:id',   name: 'picture-detail',  component: () => import('@/views/PictureDetailView.vue') },
  { path: '/upload',        name: 'picture-upload',  component: () => import('@/views/PictureUploadView.vue') },
  { path: '/admin/users',   name: 'admin-users',     component: () => import('@/views/AdminUserView.vue') },
  { path: '/admin/pictures', name: 'admin-pictures', component: () => import('@/views/PictureManageView.vue') },
]

// 导航栏路由映射
// 首页 → /  |  探索 → /gallery  |  上传 → /upload  |  审核 → /admin/pictures  |  用户 → /admin/users

const router = createRouter({
  history: createWebHistory(),    // 使用 HTML5 History 模式（无 # 号）
  routes
})
```

**懒加载**：除首页外所有页面使用 `() => import(...)` 动态导入。Vite 在生产构建时将每个 `import()` 分割为独立的 chunk，用户在访问时才加载对应 JS 文件。

## 八、Axios 封装 — `api/request.js`

```javascript
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',            // ★ 所有请求自动加 /api 前缀
  timeout: 10000,             // 10 秒超时
  withCredentials: true       // ★ 携带 Cookie（Session 认证必需）
})

// ===== 响应拦截器 =====
request.interceptors.response.use(
  (res) => {
    const body = res.data
    if (body.code === 0) {
      return body.data        // ★ 自动提取 data，调用方直接拿到业务数据
    }
    return Promise.reject(new Error(body.message || '请求失败'))
  },
  (err) => {
    const msg = err.response?.data?.message || err.message || '网络异常'
    return Promise.reject(new Error(msg))
  }
)

export default request
```

**拦截器的价值**：
- 每个 API 调用不需要重复写 `if (res.data.code === 0)`
- 统一错误处理：调用方只需 `try { const data = await api.xxx() } catch (e) { error = e.message }`
- 可集中扩展：如添加全局 loading、Token 刷新、401 自动跳转登录页

### 9.4 PictureDetailView 审核交互

- **通过**：调用 `reviewPicture({ id, reviewStatus: 1, reviewMessage })`，图片立即对公众可见

1. 当前用户为管理员
2. 图片 `reviewStatus === 0`（待审核状态）

## 十、Pinia 状态管理 — `stores/user.js`

```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { getCurrentUser, userLogin, userLogout } from '@/api/user'

export const useUserStore = defineStore('user', () => {
  const currentUser = ref(null)                            // 响应式状态

  // ★ 计算属性（computed）
  const isLoggedIn = computed(() => !!currentUser.value)   // 是否已登录
  const isAdmin = computed(() =>                            // 是否管理员
    currentUser.value?.userRole === 'admin'
  )

  // ★ 动作（actions）
  async function login(loginData) {
    const user = await userLogin(loginData)
    currentUser.value = user
    return user
  }

  async function logout() {
    await userLogout()
    currentUser.value = null
  }

  async function fetchCurrentUser() {
    try {
      currentUser.value = await getCurrentUser()
    } catch {
      currentUser.value = null                             // 未登录
    }
  }

  return { currentUser, isLoggedIn, isAdmin, login, logout, fetchCurrentUser }
})
```

**使用方式**：

```javascript
// 在任何组件中
import { useUserStore } from '@/stores/user'
const userStore = useUserStore()

// 读取状态
userStore.isLoggedIn    // → true/false
userStore.isAdmin       // → true/false
userStore.currentUser   // → { id, userAccount, userName, ... }

// 调用动作
await userStore.login({ userAccount: 'admin', userPassword: '12345678' })
await userStore.logout()
```

## 十一、页面详解

### 11.1 HomeView（首页）

组件结构：
```
HomeView
├── HeroSection          # 大标题 + 搜索框 + 热门标签
├── 特色卡片区            # 3 列网格：⚡闪电搜索 / ☁️云端存储 / 🎨策展排版
├── 精选马赛克区          # 不规则网格（4 列，大中小尺寸混合）
└── CTA 区               # 全宽黑色背景，号召注册
```

**搜索功能**：HeroSection 中的搜索框输入关键词后，`router.push({ name: 'gallery', query: { q: keyword } })`。GalleryView 在 `onMounted` 时读取 `route.query.q` 作为初始搜索词。

**热门标签**：`['风景', '人物', '街拍', '黑白', '建筑', '抽象']`，点击自动填入搜索框并跳转。

### 11.2 LoginView / RegisterView（登录 / 注册）

- 居中卡片布局（`max-width: 440px`，黑边框）
- 表单前端校验 + 后端错误提示双重反馈
- 登录成功：`userStore.login()` → `router.push(redirect 或 '/')`
- 注册成功：`userRegister()` → 显示绿色成功提示 → 1.5s 后跳转登录页

### 11.3 GalleryView（图库浏览）

核心功能：

```javascript
// 查询参数（URL 持久化）
const query = reactive({
  current: Number(route.query.page) || 1,  // ★ 从 URL 恢复页码
  pageSize: 12,
  searchText: route.query.q || '',         // ★ 从 URL 恢复搜索词
  category: '', picFormat: '', tags: null,
  sortField: 'createTime', sortOrder: 'descend'
})

// 加载图片（使用缓存版接口）
async function loadPictures() {
  const res = await listPictureVOByPage({ ...query })
  pictures.value = res.records || []
  total.value = res.total || 0
}

// ★ URL 同步（页码和搜索词写入 URL query string）
function syncUrl() {
  const q = {}
  if (query.current > 1) q.page = query.current
  if (query.searchText) q.q = query.searchText
  router.replace({ query: q })
}
```

交互：
- 搜索/筛选变化 → `handleSearch()` 重置第 1 页并重新加载
- 标签切换（多选）：`toggleTag()` 增删标签数组
- 分页导航：`goPage()` 切换页码，滚动到顶部
- **页面跳转**：输入框 + GO 按钮，`goPage(jumpPage)` 直接跳到指定页
- **URL 持久化**：每次分页/搜索操作通过 `syncUrl()` 将页码和搜索词写入 URL。用户从详情页返回时，自动恢复到之前浏览的页码
- 卡片点击：`goDetail(id)` 跳转到 `/picture/:id`

图片展示优化：
- 卡片使用 `pic.thumbnailUrl || pic.url`（优先缩略图，256px 体积小、加载快）
- CSS Grid `auto-fill` + `minmax(280px, 1fr)` 自适应列数
- 图片懒加载：`loading="lazy"` 属性
- 卡片 hover 效果：`translate(-2px, -2px)` + `box-shadow: 6px 6px 0 var(--black)`

### 11.4 PictureDetailView（图片详情）

布局：左右分栏（desktop 下 `grid-template-columns: 1fr 1fr`）

**左侧**：大图展示（黑边框容器）
- 使用 `pic.url`（webp）展示高清图片
- **全屏预览**：点击图片进入全屏模式（`<Teleport to="body">` 渲染覆盖层）
  - 黑色半透明背景，图片居中最大显示
  - ESC 键关闭全屏，点击背景也可关闭
  - 鼠标悬停时显示缩放提示

**右侧**：
- 图片名称（大标题）
- **审核状态徽标**：⏳待审核 / ✅已通过 / ❌已拒绝（带颜色背景）
- 作者信息（圆形头像首字母 + 用户名）
- 简介（或"暂无简介"）
- 元数据网格（分类、格式、尺寸、文件大小、上传时间、编辑时间）
- 标签条（黑底白字 badge）
- 操作按钮组：
  - **下载**：`<a href="/api/picture/download/{id}">`，下载原图格式
  - **编辑** / **删除**（仅作者或管理员可见）
  - **返回图库**：`router.push('/gallery')`（保留 URL 中的 page 参数）

**审核操作**（管理员，待审核图片）：
- 通过按钮：调用 `reviewPicture({ id, reviewStatus: 1 })`
- 拒绝按钮：弹出输入框填写拒绝理由 → `reviewPicture({ id, reviewStatus: 2, reviewMessage })`

**编辑弹窗**：
- 名称、简介（textarea）、分类（下拉）、标签（逗号分隔字符串）
- 保存后调用 `editPicture()` → 刷新当前页面数据

### 11.5 PictureUploadView（图片上传）

**标签页双模式**：
- **文件上传**：拖拽区域（`dragover`/`dragleave`/`drop` 事件）+ 点击选择（隐藏 `<input type="file">`）
- **URL 上传**：输入框填写图片 URL → 点击上传按钮

**前端校验**（选择文件时）：
```javascript
const allowed = ['image/jpeg', 'image/png', 'image/webp']
if (!allowed.includes(f.type)) { error = '仅支持 JPG/JPEG/PNG/WEBP 格式' }
if (f.size > 2 * 1024 * 1024)  { error = '文件大小不能超过 2MB' }
```

**上传流程**：
- 文件模式：`FormData` 封装 → `uploadPicture(formData)`
- URL 模式：`{ fileUrl, picName }` → `uploadPictureByUrl(data)`
- 上传成功后显示成功提示，2 秒后自动跳转到详情页

### 11.6 AdminUserView（用户管理）

- 表格展示（ID/账号/昵称/角色/创建时间/操作）
- 搜索栏：账号模糊、昵称模糊、角色下拉
- 分页：`上一页 / 第 N 页 共 M 页 / 下一页`
- 创建弹窗：含账号、密码、昵称、头像 URL、简介、角色
- 编辑弹窗：含昵称、头像 URL、简介、角色（不含密码和账号）
- 删除：`confirm('确定删除该用户？')` → 调用 `deleteUser(id)`

### 11.7 PictureManageView（图片审核管理）

管理员专属页面（`/admin/pictures`），功能包括：

**审核标签页**：
- 全部 / 待审核(0) / 已通过(1) / 已拒绝(2) 四个标签切换
- 搜索筛选：名称/简介模糊搜索，分类下拉筛选
- 表格展示：缩略图（`thumbnailUrl`）、名称（可点击跳转详情）、上传者、审核状态徽标、上传时间

**快捷审核操作**：
- 待审核图片：`通过` 按钮（一键通过）、`拒绝` 按钮（弹出输入框填写拒绝理由）
- 已审核图片：`查看` 跳转详情页、`删除` 按钮
- 状态徽标：⏳ 待审核（黄色）/ ✅ 已通过（绿色）/ ❌ 已拒绝（红色）

**批量抓取面板**：
- 搜索词输入（`searchText`）
- 抓取数量（`count`，1-30）
- 偏移量（`offset`，避免重复抓取）
- 名称前缀（`namePrefix`，可选）
- 调用 `uploadPictureByBatch()` → 5 分钟超时 → 显示成功数量

**分页**：支持翻页浏览

访问路径：导航栏 admin 菜单 →「审核」，或直接访问 `/admin/pictures`

## 十二、构建与部署

### 开发模式

```bash
npm run dev          # 启动 Vite 开发服务器（:5173，HMR 热更新）
```

### 生产构建

```bash
npm run build        # Vite 构建，输出到 dist/（代码分割、压缩、tree-shaking）

```

### 生产部署架构

```
浏览器
  │
  ├── /api/* ──→ Nginx 反向代理 ──→ Spring Boot (:8124)
  │
  └── /* ──────→ Nginx 静态文件 ──→ dist/ (Vue 构建产物)
```

Nginx 配置示例：

```nginx
server {
    listen 80;
    server_name example.com;

    # 静态资源（Vue SPA）
    location / {
        root /var/www/li-picture-cloud/dist;
        try_files $uri $uri/ /index.html;  # SPA fallback
    }

    # API 代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:8124;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
