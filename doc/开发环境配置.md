# 开发环境配置

## 运行环境

- Java 21
- Maven 3.9.15（优先使用仓库中的 `mvnw.cmd`）
- Node.js 22
- npm 10
- MySQL 8
- Redis 6 或更高版本
- PostgreSQL + pgvector（仅启用向量检索时需要）

## 后端配置

复制示例配置：

```powershell
Copy-Item src/main/resources/application-local.example.yaml src/main/resources/application-local.yaml
```

至少设置 MySQL 和 Redis 凭证：

```powershell
$env:MYSQL_PASSWORD = '<your-mysql-password>'
$env:REDIS_PASSWORD = '<your-redis-password>'
```

按需设置以下变量：

| 功能 | 环境变量 |
|---|---|
| MySQL | `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_DATABASE`, `MYSQL_USERNAME`, `MYSQL_PASSWORD` |
| Redis | `REDIS_PASSWORD` |
| 腾讯云 COS | `COS_HOST`, `COS_SECRET_ID`, `COS_SECRET_KEY`, `COS_REGION`, `COS_BUCKET` |
| 通义千问 | `DASHSCOPE_API_KEY` |
| 百度千帆 | `QIANFAN_API_KEY`, `QIANFAN_BEARER_TOKEN` |
| PGVector | `PGVECTOR_URL`, `PGVECTOR_USERNAME`, `PGVECTOR_PASSWORD` |
| MXAI MCP | `MXAI_API_KEY` |

真实的 `application-local.yaml`、`.env` 和密钥文件均被 Git 忽略。不要把真实凭证写入示例文件或提交历史。

## 启动与验证

### 日常开发

启动后端：

```powershell
$env:JAVA_HOME = '<path-to-jdk-21>'
.\mvnw.cmd spring-boot:run
```

启动前端：

```powershell
Set-Location li-picture-cloud-frontend
npm ci
npm run dev
```

前端开发服务器运行在 `http://localhost:5173`，并将 `/api` 代理到 `http://localhost:8124`。

### 提交前验证

本地提交前使用与 CI 相同的测试配置。该配置使用 H2 和内存 Session，不需要 MySQL、Redis、COS、AI 或 MCP 的真实密钥，也不会连接外部 MCP 服务。

后端（PowerShell）：

```powershell
$env:JAVA_HOME = '<path-to-jdk-21>'
.\mvnw.cmd -B "-Dspring.profiles.active=test" package
```

前端需要 Node.js 22 和 npm 10：

```powershell
Set-Location li-picture-cloud-frontend
npm ci
npm run build
```

GitHub Actions 会在推送到 `main` 以及 pull request 时并行执行以上两组验证。后端通过标准为 Maven 打包成功且测试零失败；前端通过标准为干净安装依赖后 Vite 生产构建成功。
