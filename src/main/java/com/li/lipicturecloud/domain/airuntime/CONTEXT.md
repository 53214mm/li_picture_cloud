# AI 运行

AI 运行上下文管理伙伴可用能力、模型与 MCP 连接、任务路由、凭据引用和平台额度，不决定伙伴人格或图片所有权。

## 能力执行

**能力**：伙伴可以发现并请求执行的一项版本化动作，带输入、输出、权限、风险、费用和副作用说明。
_Avoid_: 裸工具、函数名、插件代码

**能力目录**：当前主体在指定渠道中可见且已启用的能力快照。
_Avoid_: 全局工具数组、权限清单

**能力调用**：主体通过能力目录中的精确版本请求执行一次能力的行为。
_Avoid_: 模型命令、任意函数执行

**执行回执**：能力调用的结构化结果，说明已完成、已受理、需确认、被拒绝或结果未知。
_Avoid_: 自由文本状态、供应商原始响应

**玩法配方**：用户用受限触发器、条件和能力组合形成的声明式玩法。
_Avoid_: 脚本、宏、服务器代码

## 模型与连接

**模型连接**：一个用户或平台连接某个模型供应商所需的协议、端点、凭据引用和启用状态。
_Avoid_: 明文配置文件、模型实例

**模型能力画像**：某个具体模型经官方声明和平台验证后可实际支持的模态与功能快照。
_Avoid_: 品牌能力、模型名称猜测

**任务路由**：按能力、用户选择、伙伴覆盖、隐私、预算和健康度决定一次任务使用哪个模型连接的规则。
_Avoid_: 随机切换、静默降级

**MCP 连接**：主体连接一个经平台审核的 MCP 服务及其允许工具集合的配置。
_Avoid_: 任意 URL、全局 MCP Token

**凭据引用**：指向独立加密存储中秘密的不可读标识。
_Avoid_: API Key、Token 明文

## 费用

**费用来源**：一次外部模型调用由用户自己的供应商账户或平台额度承担的明确选择。
_Avoid_: 默认钱包、隐式兜底

**平台额度**：平台允许主体消费平台模型密钥的非负使用权，不等同于人民币余额。
_Avoid_: 现金、积分、用户 API Key

**额度桶**：一组具有来源、有效期、可用量和冻结量的平台额度。
_Avoid_: 钱包账户、订阅订单
