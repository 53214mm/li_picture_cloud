# 伙伴

伙伴上下文管理每位用户专属图像生命体的成长、记忆、反馈和受控主动行为。

## 生命与成长

**伙伴**：由一位用户长期培养、能够从授权图片和互动中成长的图像生命体。
_Avoid_: AI 机器人、聊天角色、宠物记录

**喂养**：主体明确选择授权图片，让伙伴从图片中获得一次成长结果的行为；原图片不会被删除或转移。
_Avoid_: 上传、训练模型、消费文件

**图片观察**：从一张授权图片得到、可注明来源和理解范围的受控事实；它可以只来自元数据，也可以来自视觉内容理解。
_Avoid_: 图片营养、伙伴成长、模型结论

**图片营养**：由图片观察生成、等待伙伴生命规则裁定的成长候选；它不能直接决定等级、权限或最终属性值。
_Avoid_: 图片观察、模型输出、属性写入

**请求策略**：一次喂养允许使用的观察路径，例如只读元数据或可使用视觉且允许显式降级；它不是实际发生的来源。
_Avoid_: 实际来源、内容理解、模型调用结果

**实际来源（provenance）**：一次图片营养真正采用的方式，以及 Provider、模型、版本、置信度或降级原因；它是成长记录中可审计的事实。
_Avoid_: 请求策略、当前配置、模型原始回答

**显式降级**：视觉策略因允许的安全失败原因改用元数据营养的结果。它必须被记录和展示，不能伪装成视觉理解。
_Avoid_: 视觉成功、静默重试、内容理解

**视觉日额度**：每个主体每天可预占的视觉出站次数。额度在模型调用前预占，模型失败或显式降级不退款。
_Avoid_: 经验上限、会员额度、余额

**内容理解**：实际读取图片像素并识别其视觉内容的观察方式；仅使用名称、分类、尺寸、格式或大小不属于内容理解。
_Avoid_: 元数据读取、图片营养

**成长记录**：一次喂养、互动或时间事件对伙伴产生变化的可追溯事实。
_Avoid_: 操作日志、聊天记录

**生命经验**：只增不减、用于衡量伙伴总成长进度的数值。
_Avoid_: 积分、余额、熟练度

**等级**：由累计生命经验确定的总成长刻度。
_Avoid_: 权限等级、会员等级

**生命阶段**：伙伴在长期成长中形成的可见形态阶段，例如光点、幼体或伙伴。
_Avoid_: 等级、皮肤

**性格轴**：描述伙伴长期倾向的一组双极维度，例如好奇与谨慎、创造与秩序。
_Avoid_: 当前情绪、用户设置

**情绪**：随时间、互动和事件快速变化的伙伴当前状态。
_Avoid_: 性格、永久属性

**情绪衰减**：情绪强度按完整小时向 0 自然收敛的规则；读取主页与喂养结算时惰性应用。
_Avoid_: 情绪重置、性格回归

**关系状态**：伙伴与其主人在熟悉、信任、亲密和默契方面的持续状态。
_Avoid_: 好感度余额、用户权限

**技能熟练度**：伙伴在某项能力上的练习与专精程度。
_Avoid_: 生命经验、能力权限

## 记忆与主动行为

**记忆**：由授权图片或互动支持、带来源和置信度的长期信息。
_Avoid_: 原始聊天历史、模型上下文

**记忆候选**：由一次真实内容理解的成长记录派生的待确认记忆；用户可以确认、纠正或忽略。
_Avoid_: 成长记录、模型输出、最终事实

**记忆失效**：来源图片撤权或消失后，记忆转为不再对外展示内容的状态；失效原因可审计。
_Avoid_: 删除记忆、忽略记忆

**好奇冲动**：某次机会引起、会衰减且可被立即抑制的短期行动动机。
_Avoid_: 好奇性格、主动权限

**主动提案**：伙伴在守门规则通过后，向用户提出问题、创作建议或执行请求的行为。
_Avoid_: 自动执行、随机插话、推送权限

**自主契约**：用户直接设定的主动频率、安静时段、渠道、允许能力和确认要求。
_Avoid_: 性格、系统提示词、模型偏好

**敲打**：用户对不合适主动行为作出的即时负反馈，先抑制当前冲动，重复反馈才缓慢影响性格。
_Avoid_: 删除伙伴、重置人格、惩罚积分
