# 绫页独立观察使用与边界

进入本站并登录，在右下角或 /companion/rehearsal 的“绫页·独立观察”核对当前文本和视觉BYOK接收方、计数与费用说明。选择本轮文本1–500、LOW/NORMAL强度，可选视觉0–100，然后明确开启自动观察或单次观察。6/2只是建议，未点击不收费、不自动观察。90秒后即使没有操作也可决定沉默、表情或自然短话题；普通聊天输入/进行中优先，隐藏/退出/切号/对象更改取消待结果。用尽、24小时授权到期、变更接收方需用户再次授权。

视觉仅为640×360安全灰色卡片布局，不识别图片内容；所有用户文字、照片、输入与头像在像素生成前排除。未知或敏感页面不采集。不选择视觉不生成PNG/不调用视觉模型；选择“仅预览安全布局”只返回本地几何PNG，无provider调用。说明缓存180秒且命中不续TTL，预览30秒后删除；文本模型仅收到客观caption及来源/时间/不确定性。

普通聊天/相关记忆使用既有权限；观察召回是本地词汇匹配，不触发embedding。跨标签页持久租约45秒、计数/冷却持久，刷新和新grant不重置UTC日工程硬限1000/200。授权次数不是金额上限，失败取消可能已收费；旧手动100桶继续Asia/Shanghai，旧四按钮仅协议调试。

记录展开可看每轮实际输入、原正文/partial、严格parsed和抑制原因、计数与流终止元数据。EMPTY_OUTPUT明确未取得正文，不虚构模板/不强制SPEAK/不盲目重试，最多160 token与8秒；不保留reasoning、认证头或双BYOK Key。账号内存最多50条，刷新/切号/注销清空，不写长期记忆。

部署默认开关 COMPANION_OBSERVATION_ENABLED=false（服务器能力），前端总开关VITE_ENABLE_COMPANION_UI。实际本机启用的VM参数与版本见独立交付报告；浏览器本轮授权仍默认关闭。当前单后端跨标签页聊天守卫，不宣称跨JVM普通聊天协调。真实provider质量/兼容性/人格与费用由用户自行人工验收。
