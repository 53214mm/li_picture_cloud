# 绫页站内事件接入 · 2026-10-09

## 产品范围

- AppLayout 持有一个仅内存、默认关闭的站内演示协调器。普通聊天、历史、模型设置和原 Shell 互动入口保留。
- 可选静态浮动小组件提供显式开启、暂停、短句静音、主动程度、1–12 次提交上限、已提交计数、脱敏输入检查器和动作结果。
- 仅接受实际进入伙伴页 / 图库的 `PAGE_ENTER`，及当前图片详情成功授权读取后的 `PICTURE_OPENED`。没有接上传或任意全站事件。
- 图片事件不传图片 ID、URL、名称、描述、图像、DOM、表单或聊天内容；不为事件增加图片读取。服务端 wire 仅有 `sessionId,eventId,sequence,observedAt,eventType,page`。
- 使用既有服务端 `DEMO` 适配器，真实模型 / BYOK 未开放。当前后端进入页面沉默、打开图片点头；不声称看懂图片或人格体验完成。
- 点击动作结果的回复按钮只打开既有普通聊天抽屉；没有自动发送、注入历史或改聊天模式。普通聊天仍按用户原设置计费。
- 功能开关关闭时不创建协调器，不注册其监听，不发送 presence IO。未 opt-in 时实际导航和详情加载也为零 presence IO。

## 生命周期与费用保护

- 页面切换保留本地已提交次数及冷却；本地保守统一至少 45 秒（后端仍执行自身 LOW/NORMAL 冷却）。刷新、账号变化和登出意图关闭并清理状态。
- 新事件先使旧结果失效，再判断预算 / 冷却。重复详情成功通知每次访问只处理一次；没有计时补发或可见恢复重放。
- 未支持页面、页面隐藏、Shell / 旧版弹层、聊天焦点 / 非空草稿 / 发送阶段 / 模式切换、登出意图和卸载均阻止接收。只读取这些布尔状态，不上传其内容。
- 路由最前置 guard 广播导航意图，先于已有异步鉴权。协调器按实际目标对象关联 afterEach/onError；旧导航取消不能解除新导航等待期间的抑制。失败恢复不重放页面事件。
- 进入试演台的意图即关闭现场演示，避免后端每用户一个会话的竞争。现场与试演台共用的 transport 按 API 实例串行化会话创建/关闭；创建 POST 不用客户端 abort 提前放行，等待返回后关闭失效会话，才允许下一次创建。
- 客户端 abort 只取消接收，不承诺已开始的服务端任务被取消。网络失败 / DELETE 失败不冒充关闭成功；后端会话有既有最多 15 分钟到期，且不会自发执行后台决策。没有自动重试或真实收费调用。
- 事件 ID 限制对齐服务端 64 字符。保留生产 Java long 十进制字符串序号的严格相关性检查。

## 图片详情窄范围修复

- 当前路由、精确图片 ID、账号、实例及导航意图共同约束详情 / 权限 / 类别响应和写入后的 UI 回调；不允许旧响应替换新图片或触发迟到跳转。
- 主详情不再等待无关类别元数据或空间权限。仅匹配当前 ID 的成功授权详情读取可发零载荷通知；错误、空、错 ID、旧读取不发。
- 取消导航可重新读取当前详情，但已通知的当前访问不重放。复用组件切换图片 ID 时重新加载。
- 编辑器按打开生命周期挂载；旧异步导出 / 上传回调不能覆盖新图片或关闭重新打开的编辑器。后端权限与写入语义未改。
