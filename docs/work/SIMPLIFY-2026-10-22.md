# 精简：删除伙伴主动类功能、创作与 MCP 管理（2026-10-22）

## 为什么删

伙伴系统功能太多，三套"她主动找你"的机制（独立观察、站内主动冒泡、主动提议）叠在一起，逻辑最绕、bug 最多，维护不过来。创作和 MCP 管理也基本没在用。删掉之后，伙伴只剩"你找她"这一条主线，好维护，也好讲清楚。

删除前的最后一个提交是 `40add60`，需要找回某个功能时从那里取。

## 删了什么

| 功能 | 后端 | 前端 |
|---|---|---|
| 独立观察 | `application/companion/observation`、`/companion/observation/*`、聊天优先切面、`chatEpoch` 计数 | 观察面板与气泡、页面上的 `data-observation-*` 标记 |
| 主动冒泡 + 试演台 | `application/companion/presence`、`/companion/presence/*`、额度表读写 | `/companion/rehearsal` 试演台、站内冒泡组件 |
| 主动提议 | 提议服务、三种机会来源、安静时段契约、`/companion/proposals/*`、`/companion/contract` | 提议面板、侧边栏"待回应提议"标记、动画里的"注意"状态 |
| 喂养诊断后台 | `/admin/companion/feed-runs` | 喂养日志页面 |
| 创作 | 故事、表情、融合、配方工坊（`/creation/*`、`/recipe/*`） | 留影手记里的故事/表情/融合面板、配方工坊页 |
| MCP 白名单管理 | 服务登记、工具白名单、`/model/mcp/*` | 模型连接页高级设置里的 MCP 区块 |

## 保留什么

- 喂图与识图、图片记忆（pgvector 向量召回）、成长 / 心情 / 关系
- 聊天：人格、对话分段、聊天经历、自己的 Key 优先的模型路由
- 模型连接（快速连接、高级设置、调用记录分页）
- 图库、空间、AI 助手

## 几处调整

- **清空对话记录**：原来在试演台，现在在伙伴页聊天区下方，点击后需要再确认一次。
- **AI 助手的 MCP 工具**：不再从数据库白名单读取，改为配置 `app.ai.mcp.allowed-tools`（逗号分隔，比如 `generate_image,get_task_status`），默认为空，即一个工具都不放行，和原来没配白名单时一样。
- **图片详情页**：跳转时丢弃旧加载结果的那个小工具保留下来，改名为 `presentation/navigationIntent.js`。

## 数据库

表和 Liquibase 迁移全部保留，没有删表、没有删数据，只是代码不再读写：`companion_observation_usage`、`companion_presence_usage`、`companion_proposal`、`companion_proposal_reaction`、`companion_autonomy_contract`、`creation_*`、`recipe*`、`mcp_*`，以及 `companion_chat_boundary.chatEpoch` 列。以后确定不要了，可以再单独加一个删表的迁移。

## 验证

- 后端：`mvn clean test` 全部通过（删除后 679 项）。
- 前端：单元测试、lint、生产构建通过；用模拟接口的浏览器测试结果见提交说明。
- 需要真实后端的 API 端到端测试（`npm run test:api:e2e`）没有在本机跑。
