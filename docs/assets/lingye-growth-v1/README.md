# 绫页成长外观草案 v1

这是用户授权的首版视觉提案，不是已接入的运行时成长素材。概念图从现有 `src/assets/companion/lingye/adult-home-v1.webp` 衍生，保留棕色短发、灰绿眼、折纸发饰、深蓝/米白宽袖披肩、金色书签挂饰和短靴。

左→右采用更紧凑的Q版、过渡比例、现有成熟比例，表情略开朗。不把绫页变成飞蛾/光球，不以缩小同一成年立绘冒充不同阶段。仍需用户确认比例、表情与角色辨识度。

- 生成方式：内置图像生成，引用本项目现有立绘；未使用用户API key
- 文件：concept-sheet.png，1536×1024 RGBA
- 核验：已查看像素；三体轮廓与主要配色/服装/发型可辨。图中仍有环境光晕/半透明背景，不能当作合格单体透明sprite直接上线
- 状态：未裁切、未替换既有资产、未接入构建。当前UI只完成静态展示与统一称呼，阶段渲染仍待单体素材与视觉验收
- 下一步：用户选定方向后分别制作三张干净透明单体，检查头发/脸部/配饰一致性、轮廓与固定锚点，再接stage映射

## 使用的提示词要点

Identity-preserve / stylized-concept；相同绫页角色，三体底部对齐由小到大，约2.5/4/6头身，左轻挥手、中双手叉腰、右轻松微笑。保留参考图完整设计语言和服装，不新增动物形态/翅膀/配饰，不做文字水印。要求透明背景，输出实际存在光晕，故明确仅为草案。
