## 协同编辑跨实例一致性

- 状态：不阻塞单实例运行，但部署多个后端实例前必须处理。
- 原因：第 8 轮的房间连接和编辑状态保存在单个 JVM 内存中。若负载均衡把同一图片的用户分配到不同实例，双方收不到彼此事件。
- 临时约束：协同 WebSocket 使用单实例，或在网关按 `pictureId` 做粘性路由。
- 推荐最终方案：Redis 保存状态和版本，Redis Stream / PubSub 广播房间事件；命令幂等键设置过期时间。完成后增加双实例集成测试。
