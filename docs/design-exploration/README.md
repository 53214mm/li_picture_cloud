# R01 设计探索（Design Exploration）

本目录是 **R01 — 新视觉设计体系 · 需求确认阶段** 的视觉草图，用于表达三套视觉方向。

## 约束声明

- 本目录全部为**独立静态 HTML**，与正式项目隔离
- 不接真实 API、不含真实数据、不引入任何依赖（无构建、无 npm 包）
- 图片均为 CSS 渐变占位
- **不构成最终方案**，未被合入任何正式页面、样式或配置
- 正式代码、CSS、Vue 文件、依赖、Git 历史在本阶段均未被修改
- 方向 C 草图中的"饥饿""它最喜欢这张""环境色取自图片"等表达为**概念表现**，当前均非已有领域事实，不构成任何后端需求或业务语义承诺

## 文件

| 文件 | 方向 |
| --- | --- |
| `index.html` | 索引页 |
| `direction-a-paper-space.html` | 方向 A · 雾屿纸境 — 安静的个人数字空间 |
| `direction-b-darkroom.html` | 方向 B · 暗房 — 沉浸式影像世界 |
| `direction-c-ambient-habitat.html` | 方向 C · 生息之间 — 数字生命空间 UI |

直接用浏览器打开任一 HTML 文件即可查看。

论证与推荐见 `docs/R01-新视觉设计体系-需求确认报告.md`。
