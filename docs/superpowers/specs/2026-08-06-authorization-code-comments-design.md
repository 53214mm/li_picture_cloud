# 权限代码教学型注释设计

## 目标

为权限主链上的 5 个 Java 文件补充面向初学者的中文教学注释，使读者能够按照“声明权限 → AOP 解析 → 资源上下文解析 → 权限决策 → Sa-Token 兼容入口”理解代码。

## 修改范围

- `SpacePermission`：解释注解用途、权限码、三种资源表达式和 SpEL 示例。
- `SpacePermissionInterceptor`：解释 AOP 切面、`#p0/#a0` 参数变量、资源唯一性约束、请求获取与放行。
- `SpaceAuthorizationAccessService`：解释门面职责，以及空间、图片、成员关系如何统一解析成授权资源。
- `SpaceAuthorizationManager`：解释公共图片、个人空间、团队空间三类决策规则和平台管理员处理。
- `StpInterfaceImpl`：解释 Sa-Token `StpInterface` 的调用背景、请求上下文推断流程，以及它和统一授权服务的区别。

## 注释风格

- 类级注释先回答“这个类在整条链路中做什么”。
- 方法级注释说明调用者、参数、返回值和边界。
- 只在关键分支解释“为什么”，不逐行翻译 Java 语法。
- 使用简短示例解释 `#p0.spaceId`、`joinPoint.proceed()` 和角色到权限码的映射。
- 不把无法由源码证明的历史原因写成事实；`StpInterfaceImpl` 描述为 Sa-Token 权限加载路径，不武断标注为废弃代码。

## 非目标

- 不修改条件、返回值、异常类型、依赖关系或方法签名。
- 不重构重复授权实现。
- 不修改业务代码、配置文件或测试。

## 验收

- 5 个目标文件只有注释或纯格式变化。
- 注释能串起完整权限链，且没有误导性表述。
- `git diff --check` 通过。
- 使用 Maven 跳过测试执行编译，确认注释没有破坏源码；不运行前端和完整后端测试。
