# LiPictureCloud 校招面试文档设计

## 目标

围绕 LiPictureCloud 项目，为 Java 后端实习/校招面试定制一套可在 10 天内执行的学习与模拟面试文档。

文档不追求覆盖所有 Java 知识，而是帮助学习者做到：

1. 能独立讲清项目业务、架构和主要请求链路。
2. 能围绕六个核心技术亮点承受至少三层追问。
3. 补齐 Java、Spring、MySQL、Redis 的校招高频基础。
4. 能诚实区分已实现功能、可选能力和后续规划。
5. 能用自己的语言回答，而不是背诵与代码不一致的模板。

## 学习者画像

- 目标岗位：Java 后端实习/校招。
- 准备周期：1 至 2 周。
- 每日可投入时间：5 至 6 小时。
- 已掌握：表设计、索引选择、CRUD、常见业务逻辑、接口实现、Redis 缓存、MySQL 索引与事务、AI 记忆/知识库/工具调用/拦截器/Agent。
- 需要强化：Redis Lua、WebSocket 连接与消息流程、ShardingSphere、Spring/Spring MVC 原理、Spring Boot 自动配置、MySQL 联表查询。
- 基础缺口：Java 集合、并发、JMM、JVM 和常见八股表达。

## 写作原则

1. 以当前仓库代码为唯一项目事实来源。
2. 每章从“为什么需要”开始，再讲流程、原理、面试回答和源码入口。
3. 使用适合初学者的中文解释，技术名词保留英文。
4. 对已熟悉的 AI 与常规业务压缩复习篇幅，把时间留给高风险短板。
5. 不虚构 QPS、并发量、性能提升百分比或生产规模。
6. 明确说明分表是可选 Profile，不能声称线上默认启用。
7. 明确说明完整 DDD 改造仍是后续方向。
8. 每个标准回答均提供“必须理解的关键词”和“不能夸大的边界”。

### 00-冲刺使用指南

提供整套文档的使用顺序、每日时间分配、知识优先级、主动回忆方法和错题记录模板。定义面试准备的最低完成标准，防止只阅读不输出。

### 01-项目全流程与自我介绍

包含：

- 30 秒、2 分钟、5 分钟三种项目介绍。
- 用户、图片、空间、空间成员等核心数据关系。
- 浏览器到 Nginx、Vue、Controller、Service、MySQL/Redis/COS，再返回前端的完整链路。
- 图片上传、团队空间访问、协同编辑、AI 生图、图库分析五条业务主流程。
- “我负责什么”的真实性表达模板。
- 项目不足和后续演进回答。

### 02-核心技术补课

重点解释项目中的高风险技术：

- Spring MVC 请求流程与 Spring Boot 启动/自动配置。
- Sa-Token、Session、空间角色与权限码。
- WebSocket HTTP Upgrade、握手拦截、Session、消息处理与断线重连。
- Redis Lua 的原子执行、幂等命令和版本控制。
- Redis Pub/Sub 与多后端实例的消息传播。
- ShardingSphere 分片键、路由、静态/动态分表与关闭方式。
- Nginx 对 REST、SSE、WebSocket 的不同代理配置。
- AI Agent、MCP 和用户上下文隔离的项目化复习。

统一模板：

```text
一句话是什么
为什么项目需要它
项目具体在哪里使用
完整执行流程
核心原理
面试标准回答
三层追问
容易说错的地方
不会时如何诚实收口
对应源码入口
```

### 03-Java与框架高频保命题

仅覆盖 10 天内收益最高的校招题：

- Java 集合：ArrayList、LinkedList、HashMap、ConcurrentHashMap。
- 并发：线程创建、线程池参数、锁、volatile、JMM、ThreadLocal。
- JVM：运行时内存、对象创建、类加载、GC 基础和常见 OOM。
- Spring：IOC、AOP、Bean 生命周期、事务传播和事务失效。
- Spring Boot：启动过程、自动配置、条件装配、配置加载。
- MySQL：B+Tree、索引、回表、覆盖索引、事务、隔离级别、MVCC、JOIN 基础。
- Redis：数据结构、缓存穿透/击穿/雪崩、持久化、过期与淘汰。

每题包含一句话回答、60 秒回答、追问和与项目的连接点。

### 04-项目追问题库

问题按四层组织：

- L1 业务层：功能解决什么问题。
- L2 实现层：代码、请求和数据如何流动。
- L3 原理层：技术为什么能工作。
- L4 质疑层：替代方案、缺陷、边界和故障处理。

覆盖图片、空间权限、协同、Redis、分表、AI、安全、部署、故障排查和项目真实性。

每题提供参考回答、关键词、危险回答、继续追问、诚实收口和源码入口。

### 05-十天训练与模拟面试

提供十天任务清单、每日验收标准、错题表和三套模拟面试卷：

1. 友好的一面基础筛选。
2. 围绕项目连续深挖。
3. 质疑选型和真实性的压力面。

## 技术优先级

### 红色必补

- Java 集合、线程池、锁、JMM、JVM。
- Spring IOC、AOP、Bean 生命周期、事务。
- Spring Boot 启动、自动配置与条件装配。
- WebSocket 握手、连接、消息和重连。
- ShardingSphere 分片概念和项目配置。

### 黄色项目强化

- Redis 缓存问题和一致性。
- Redis Lua、版本控制、幂等、Pub/Sub。
- MySQL 联表、索引、事务和 MVCC。
- Spring MVC 请求链。
- Docker 网络和 Nginx 代理。

### 绿色优势转化

- AI 记忆、知识库、Advisor、工具调用和 Agent。
- MCP 回调用户上下文污染问题。
- AI 生图结果归属和安全限制。

### 灰色暂缓

- JVM 参数大全和深度调优。
- Spring、ShardingSphere 源码逐行分析。
- 完整分布式事务方案。
- 超大规模高并发架构。
- 完整 DDD 战术重构。

## 评分标准

| 维度 | 分值 |
| --- | ---: |
| 业务理解与项目流程 | 25 |
| 技术原理 | 25 |
| Java/Spring/MySQL 基础 | 25 |
| 设计取舍与排障能力 | 15 |
| 表达、真实性与边界意识 | 10 |

每套模拟卷给出逐题评分点和总分解释：低于 60 分优先补项目主流程及高频基础；60 至 75 分可开始投递并持续复盘；75 分以上进入更强的压力追问训练。分数只用于学习诊断，不代表真实录用概率。

## 源码引用规则

- 使用仓库相对路径引用文件，必要时标注类或方法名。
- 不写易随编辑漂移的固定行号。
- 每个核心技术章节至少提供一个主入口和一个关键实现入口。
- 面试答案不要求背类名，但学习时必须能够沿入口复述数据流。

## 风险与诚实边界

- 不将 AI 辅助完成的代码描述为完全手写；回答时强调需求分析、方案取舍、验证和排障过程。
- 不知道底层源码时，先回答掌握的调用链和核心机制，再明确未深入源码。
- 不把可选的 ShardingSphere Profile 说成线上生产默认方案。
- 不把单机或资源受限部署包装成百万并发架构。
- 不把局部领域对象整理说成完整 DDD 落地。
- 文档中的“标准回答”必须经过个人复述改写，禁止机械背诵。

## 验收标准

1. 六份文档全部存在且目录导航完整。
2. 30 秒、2 分钟、5 分钟项目介绍均可直接练习。
3. 五条业务主流程均包含数据流、关键类和异常路径。
4. WebSocket、Lua、Pub/Sub、ShardingSphere、Spring Boot 自动配置均有小白解释和三层追问。
5. Java/Spring/MySQL/Redis 高频保命题覆盖上述指定范围。
6. 项目题库覆盖 L1 至 L4，并含参考答案和危险回答。
7. 十天计划每天都有具体任务和可判断的验收标准。
8. 三套模拟卷都有评分点、追问和复盘方式。
9. 所有源码路径和文档链接均真实存在。
10. 文档不包含秘密、虚构指标或不符合当前代码的技术声明。
