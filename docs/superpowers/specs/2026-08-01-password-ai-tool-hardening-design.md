# 密码与 AI 工具安全收口设计

## 1. 目标

本轮解决两个生产安全问题，同时保留现有 MCP AI 生图并自动保存图片的核心业务：

1. 用户密码从固定盐 MD5 完全切换为 BCrypt。
2. AI 不再拥有通用终端、通用文件读写和通用资源下载能力。
3. MCP 的 `generate_image`、`generate_video`、`get_task_status` 等远程生成工具继续可用。
4. MCP 返回图片地址后，后端继续自动上传到腾讯云 COS，并写入当前用户真正的私有空间。

## 2. 明确不做的事情

- 不兼容或自动升级已有 MD5 密码。
- 不提供“忘记密码”邮件或短信流程，因为当前系统没有经过验证的邮箱、手机号身份链路。
- 不删除 MCP 工具，也不删除图片搜索、图片分析、公开图库查询等受控业务工具。
- 不允许生产环境通过配置重新打开终端和通用文件工具；危险工具从注册表中直接移除。
- 不修改当前用户本地的 `application.yaml`。

## 3. BCrypt 密码方案

### 3.1 编码与验证

新增统一的密码编码组件，注册、管理员创建用户和登录都只能通过该组件处理密码：

- 写入数据库时使用 BCrypt，强度参数为 12。
- 登录时只接受合法 BCrypt 密文。
- 固定盐常量和所有 `DigestUtil.md5Hex` 密码逻辑全部删除。
- 日志和接口响应不得区分“账号不存在”和“旧密码格式”，统一返回账号或密码错误。

### 3.2 现有账号处理

这是用户选择的“方案 A”：已有 MD5 密文不会继续登录，也不会在登录时平滑迁移。

当前项目尚未正式上线，因此采用重新初始化测试账号的方式：

1. 保留图片、空间等业务数据时，由数据库管理员为指定账号写入离线生成的 BCrypt 密文。
2. 不需要保留账号数据时，清理开发数据库后通过注册接口重新创建账号。
3. 新部署环境先注册一个账号，再由数据库管理员将其 `userRole` 更新为 `admin`。

文档必须强调：不能使用在线网站生成生产密码散列，也不能把明文密码写进 SQL、Git 或启动日志。

## 4. AI 工具边界

### 4.1 删除的本地工具

以下工具不再创建，也不再进入传给模型的 `ToolCallback[]`：

- `TerminalOperationTool`
- `FileOperationTool`
- `ResourceDownloadTool`
- `PDFGenerationTool`（其读取、写入、合并和拆分接口同样接受服务器文件路径）

对应 Java 类一并删除，避免后来误注册。`ToolRegistration` 中仍保留图片平台业务确实需要的本地工具。

### 4.2 保留的能力

- `AIGenerationTool`：受当前登录用户上下文约束，将指定图片 URL 保存到用户私有空间。
- `PictureManageTool`：只查询公开且已审核的图片。
- `PictureAnalysisTool`：图片业务分析。
- MCP 远程工具：继续由 `RefreshableMcpToolProvider` 动态获取和注入。

`PicCloudApp` 合并本地安全工具与 MCP 工具的机制保持不变，因此移除三个本地危险工具不会影响 MCP 生图。

## 5. 自动保存数据流

当前 `RefreshableMcpToolProvider` 已经在生成任务完成和 `get_task_status` 返回图片 URL 时执行后端自动保存。本轮保留这条确定性流程，不再额外让模型重复调用一次保存工具。

保存规则统一为：

1. 从真实登录用户上下文取得用户 ID。
2. 只查询 `userId = 当前用户` 且 `spaceType = PRIVATE` 的空间。
3. 如果没有私有空间，不保存，并在 MCP 工具结果中明确返回“未保存：请先创建个人空间”。
4. 如果存在私有空间，选择创建时间最早的一条作为当前个人空间。
5. 通过现有 `PictureService.uploadPicture` 下载、校验、上传 COS 并写入数据库。
6. 保存成功返回图片 ID 和空间名称；失败返回不包含内部异常细节的提示，同时服务端记录异常。

`AIGenerationTool.saveToMySpace` 与 MCP 自动保存必须复用同一个“个人空间选择与保存”服务，不能各写一套查询逻辑。

## 6. 安全边界

- 图片 URL 必须由现有 URL 上传流程执行协议、响应大小、图片格式与超时校验；不得把远程内容先写进任意服务器路径。
- 用户身份只能来自 `UserContextHolder`，工具参数不能声明或覆盖用户 ID、管理员身份或目标空间。
- 自动保存不得写入团队空间，即使当前用户是团队空间创建者。
- AI 返回给用户的错误信息不得包含 COS 密钥、数据库信息、服务器路径或异常堆栈。

## 7. 测试设计

必须按照 RED → GREEN 完成以下回归测试：

1. 注册和管理员新增账号保存的是 BCrypt 密文，且可以通过正确密码验证。
2. 登录可以验证 BCrypt 密码，拒绝错误密码和旧的 32 位 MD5 密文。
3. 本地 AI 工具清单不包含终端、文件读写和资源下载工具，但包含图片保存、图片管理和图片分析工具。
4. 私有空间选择器忽略团队空间；没有私有空间时返回明确未保存结果。
5. MCP 自动保存和手动 `saveToMySpace` 复用相同服务，并把图片保存到私有空间。
6. 完整 Maven 测试、前端测试、lint、生产构建、包体预算和依赖审计继续通过。
