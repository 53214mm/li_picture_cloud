# 图片炼金 MVP 设计（第一年第四季度）

> 日期：2026-08-14
>
> 依据：三年规划第四季度（2027-05—2027-08）"图片炼金 MVP 与小规模内测"；
> 第 19 轮 brainstorm 的路线 A（图像炼金工坊）与双模型引擎设计。
>
> 性质：**规格先行**。实现排期在第四季度，依赖 Q3 模型网关的图片创作路由。

## 1. 目标

让伙伴把用户的图片变成**可保存回图库的新作品**，完成"喂图 → 理解 → 成长 → 记忆 → 对话 →
主动提案 → 创作 → 保存回图库"的第一年完整闭环。

第一年验收标准：

- 用户无需学习 Prompt 即可完成至少一种创作；
- 出现稳定的再次喂图与作品保存行为。

## 2. 首批玩法（三个纵向切片）

### 2.1 图片故事草稿

- 用户确认一张（或多张）授权图片 → 伙伴生成**短篇故事**：先给大纲和草稿，用户确认后形成可保存作品。
- 数据流：授权图片 → 视觉理解（可选）→ 语言模型（伙伴 persona）→ 大纲 → 草稿 → 用户确认 → 保存。

### 2.2 表情草稿

- 从图片提取可复用元素，生成表情草稿与"聊天回怼候选"。
- 第一版以"文字版表情候选"为主（避免 Q4 就依赖图像模型），图像表情在图片创作 Adapter 就绪后接入。

### 2.3 多图融合

- 多张授权图片融合为新图片，来源图不被覆盖。
- 依赖 Q3 图片创作路由（`gpt-image-2` 设计默认）；本切片在 Adapter 就绪后启用。

## 3. 领域模型（草案）

### 3.1 创作任务 `CreationTask`

- 字段：`id, subjectId, kind(STORY_DRAFT/EMOJI_DRAFT/IMAGE_FUSION),
  sourcePictureIds, status(PENDING/OUTLINING/DRAFTING/AWAITING_CONFIRM/SAVING/SAVED/FAILED/EXPIRED),
  outlineText, draftText, resultPictureId, modelConnectionId, revision, 时间戳`。
- 状态机：`PENDING → OUTLINING → DRAFTING → AWAITING_CONFIRM → SAVING → SAVED`；
  任意中间态可 `FAILED`；`AWAITING_CONFIRM` 超时 `EXPIRED`。
- 幂等：同一请求键只创建一个任务。

### 3.2 创作血缘 `CreationLineage`

- 追加式：`id, resultPictureId, sourcePictureId, capabilityId, modelCode, promptTemplateVersion, costSource, createdTime`。
- 来源图片删除/撤权后，血缘保留（引用 ID），衍生产品按撤权规则处理。

### 3.3 创作确认

- 大纲与草稿阶段都需用户确认才进入下一步；保存回图库前再次确认目标空间与可见性。

## 4. 与现有系统的整合

- **伙伴作为创作者**：创作任务由伙伴发起（聊天/提案里建议），复用站内对话的展示语言。
- **能力路由**：故事草稿走语言路由；表情/融合走图片创作路由（Q3 网关产物）。
- **保存**：复用现有图片上传/保存管线（`AiPictureSaveService` 语义），目标空间由用户选择且后端校验权限。
- **预算**：创作是异步任务，报价 → 预留 → 结算，平台试用额度硬上限（Q3 账本）。

## 5. 安全与隐私

- 创作只使用已授权图片；原图永不覆盖（新作品是新图片）。
- 草稿/大纲是伙伴生成内容，保存为普通文本，不复制用户原文；日志不记录草稿正文。
- 异步任务引用图片 ID，不复制字节；执行前重新校验 `PICTURE_VIEW`。
- 生成结果入库遵循现有审核/可见性规则。

## 6. 内测（20—100 名受控种子用户）

- 关键观察：故事发起率/完成率/保存率、表情回怼采纳率、融合图保存率。
- 访谈节奏与数据复盘按 roadmap 第 10 节指标执行。

## 7. 明确不做

- 不自动把生成结果写入用户空间（必须确认目标空间）。
- 不做配方工坊、批量创作、付费档位（第二年）。
- 不让人脸识别结果进入创作提示词。

## 8. 验收条件（第一年）

- 端到端闭环可用：图片喂养、记忆、对话、主动提案、首批创作和回存；
- 用户无需学习 Prompt 即可完成至少一种创作；
- 能明确算出每位活跃用户的视觉、语言和图片生成成本；
- 出现稳定的再次喂图与作品保存行为后，才进入第二年规模化建设。
