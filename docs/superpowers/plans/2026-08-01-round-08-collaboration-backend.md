# 第 8 轮实施计划：协同编辑 WebSocket 后端

## 目标

只允许团队空间编辑者和管理员加入图片协同房间，服务端统一处理左旋、右旋、放大和缩小，并把结果与操作提示实时广播给房间成员。

## 实施内容

1. 引入 Spring WebSocket。
2. 定义命令、操作、状态和事件模型。
3. 建立内存会话服务，维护旋转角度、缩放比例、版本和命令幂等。
4. 握手拦截器读取服务端 Session，校验 `collaboration:edit`。
5. 消息处理器每条命令再次校验权限，执行后广播权威状态。
6. 限制允许的 Origin，默认只允许本地前端，可由环境变量覆盖。
7. 单元测试状态机、版本冲突、幂等和握手身份。

## 验收

- 私有空间、公共图库、viewer、匿名用户不能加入。
- editor/admin 可加入并操作。
- 重复命令不重复改变状态。
- 旧版本命令收到错误和最新状态。
- 每条广播包含操作者、操作、完整状态和文本提示。
