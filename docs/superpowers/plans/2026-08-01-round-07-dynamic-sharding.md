# 第 7 轮实施计划：动态分表算法与模式开关

## 目标

提供单表、静态双表、动态四表三种互斥运行方式，并用纯单元测试验证动态路由算法。

## 路由契约

1. 有 `spaceId` 时使用 `spaceId`，保证同一空间的图片进入同一物理表。
2. 公共图片没有 `spaceId`，回退使用非空的 `userId`。
3. 写入必须带有上述至少一个键；查询没有路由键时广播，优先保证结果正确。
4. 目标表后缀为 `floorMod(key, shardCount)`，可正确处理边界值。

## 模式

- 单表：不启用任何 sharding profile。
- 静态：启用 `sharding-static`。
- 动态：启用 `sharding-dynamic`。
- 禁用分表：移除 sharding profile，应用回到普通 MySQL 数据源。

## 验证

- 算法测试覆盖空间、公共图片和无键广播。
- 配置契约测试确认三个模式入口独立存在。
- 默认 test profile 完整打包，确认关闭分表时无回归。
