# 第 9 轮实施计划：协同编辑前端与保存闭环

## 目标

在现有图片编辑弹窗上启用团队协同，让用户实时看到权威状态、成员操作提示和连接状态，并能把最终效果保存回原图片。

## 实施内容

1. 独立 WebSocket 客户端，支持事件订阅、版本命令和指数退避重连。
2. 权限接口决定是否显示“协同编辑”，不依赖图片所有者判断。
3. 编辑器协同模式只开放左旋、右旋、放大、缩小。
4. 服务端事件驱动 Canvas 使用绝对 rotation/scale 重绘，避免重复增量造成漂移。
5. 保留原上传替换流程作为保存动作，并修正团队 editor 的后端保存权限。
6. Node 契约测试模拟连接、收状态、发命令、异常断线和主动关闭。
7. CI 增加前端测试步骤，再运行 lint、build 和 bundle budget。

## 验收

- 团队 editor/admin 看到协同入口，viewer 不显示。
- 两端收到同一服务端状态与中文操作提示。
- 非主动断线按 1、2、4、8、10 秒上限重连。
- 保存后沿用原接口替换图片并刷新详情。
- 前端测试、lint、build、包体检查全部通过。
