## 1. 失败诊断：为什么前五版都没过关

astra 的五轮探索（A 行式相册 / B 瀑布流 / C 展墙 / D 整齐网格 / 原版微调）反馈轨迹：

| 版本 | 用户反馈 | 暴露的问题 |
| --- | --- | --- |
| A / B / C | "图片大小参差不齐、不如原版舒服" | 自由比例 = 乱，秩序感是硬需求 |
| D 整齐网格 | "不如原版" | 与原版同构但**信息变少**（标题 hover 才出现、筛选折叠） |
| 原版微调 | "依旧不好看" | 只柔化边框阴影，页面构成原封不动，**没有可感知的升级** |

结论：**问题从来不在布局算法，而在视觉权重的分配。** 五版都在"网格怎么排"上摇摆，但原版真正不好看的地方是：

1. 每张图被**常驻黑色渐变遮罩**压住（名称/作者/日期/3 个标签全在图上，`GalleryView.vue` card-overlay）——图片从未被完整、安静地展示过；
2. 页首 + 搜索 + 三个 select + 整片标签区，**控件占掉首屏约 320px**，图片从 y≈390 才开始；
3. 2px 边框 + hover 位移硬阴影的"课程项目卡片感"。

微调版只修了第 3 点的一半，第 1、2 点原样保留——所以"依旧不好看"。D 修了遮罩却**连信息一起删掉**——所以"不如原版"。

## 2. 从反馈轨迹读出的设计约束

- **秩序是底线**：等大、对齐、间距恒定的网格（A/B/C 的参差不可接受）；
- **信息必须常驻可读**：名称/作者/日期要一直在（D 的失败），但不能压在图上（原版的失败）——**只能移到图下**；
- **控件要趁手但不能是主角**：搜索/筛选/标签可见可用，但占用面积必须大幅收敛；
- **升级必须"一眼可见"**：不是柔化边角，而是页面气质的整体换代。

## 3. 设计方案「纸境图墙」

**一句话：网格骨架保持原版的整齐，把信息从图上搬到图下，把控件从三层收成一行，把看图从跳页变成图层。**

### 3.1 页面构成（自上而下）

```
┌ 页首一行：图库（20px/600） ………………… 共 128 张
├ 检索一行：搜索框(≤440px) · 分类 · 格式 · 排序 · [标签②]  ← 高 42px
├ 标签面板：点击"标签"展开的 chip 行（默认收起，带已选计数）
├ 条件 chips：仅在筛选项激活时出现 + 清除全部
├ 图墙：等大网格，信息在图下
└ 分页：居中轻量页码 · 每页 16
```

首屏控件高度从 ~320px 压到 ~90px；首图从 y≈390 提前到 y≈220（App Shell 下估算，需实测）。

### 3.2 图墙与 tile（核心动作）

- **网格**：`repeat(auto-fill, minmax(300px, 1fr))`，gap 24px（≤1024 收 16px，≤768 两列收 12px）；流式宽度，不设全站 max-width（确认约束④）。
- **画框**：4:3、`object-fit: cover`、`border-radius: 10px`（radius-m）、**无边框无遮罩**，底衬 bg-subtle 防跳动。
- **信息在图下常驻**（不再遮挡图片 1 个像素）：
  - 第一行：名称 14.5px/500，单行截断；
  - 第二行：作者 · 日期 · 标签 12.5px tertiary，单行截断。
- **hover（桌面）**：图片 `scale(1.035)` 420ms entrance 缓动 + 柔和 shadow-m + 名称变 accent-strong；无位移跳动。`hover:none` 设备无任何功能损失（信息本已常驻）。
- **进场**：首屏 tile 依次 fade-rise（480ms entrance，45ms  stagger，上限 400ms），图片 decode 后 420ms 淡入。
- **单图失败**：原尺寸占位 + "图片暂时无法显示"，不塌陷。

### 3.3 Viewer（看图层）

点击 tile 不再直接跳详情页，先开**看图层**：

- 底：中性深灰 `#161311`（摄影看图需要中性暗底——R01 风险表对策的落地；**这是一次性看图表面，不是暗房主题**，不引入主题切换）；
- 图：`contain` 完整图（网格 cover 裁切的补偿——任何图都能被完整看到）；
- 顶栏：左 "n / 16"，右 "打开详情页"（进 `/picture/:id`，编辑/下载/删除/审核等业务动作**仍只在详情页**）+ 关闭；
- 底部：名称 + 作者·日期·标签；←/→ 在当前页已加载范围内切换，端点 disabled；
- Esc / 点击舞台空白关闭；关闭后焦点归还触发 tile、滚动位置不动（列表从未卸载，天然无 R04-astra §16 的恢复问题）；背景滚动锁；
- 层级走 overlay/modal 体系（≥300），恒高于 `--lp-z-companion:150`——看图层激活时伙伴 Presence 退后。

### 3.4 状态（六态，原型可切）

| 状态 | 呈现 |
| --- | --- |
| 加载中 | 8 个 4:3 骨架 + 柔和 shimmer，布局不塌 |
| 默认 | 16 tile + 分页 |
| 已应用筛选 | chips 可见 + 计数同步 + 结果网格 |
| 搜索无结果 | "没有符合条件的图片" + 保留条件 chips + 清除筛选（不伪装成空库） |
| 空图库 | "暂无图片 · 公开图库还没有可展示的图片。"（访客不被命令上传） |
| 加载失败 | "图片列表加载失败" + 重试，条件保留 |

### 3.5 响应式与动效

- 断点 1024 / 768 / 480 字面量（确认约束⑤）；≤768 网格两列、检索行换行、搜索整行；Viewer 手机全屏、隐藏侧箭（轻扫/按钮在实现阶段定，不发明手势）。
- 动效只用 UI 通道（160/240/420ms）+ entrance 缓动；无 ambient 通道（伙伴专用）；`prefers-reduced-motion` 全部停止。
- 触控目标 ≥44px（检索行 42px + 内容补足，实现时按 44 校验）。

## 8. 验收标准（方向确认后的实施验收）

1. 网格等大对齐：任意视口下同行 tile 顶/底对齐，gap 恒定（24/16/12 三档）。
2. 图片零遮挡：tile 图上无常驻遮罩/渐变/文字；信息全部在图下两行内。
3. 首屏（1440×900，App Shell）：首图 y ≤ 220px；图片框面积占比 ≥ 45%（同口径优于原 ~40%）；Public 变体另行实测记录。
4. 控件单行化：检索行一行完成（≤768 允许两行）；标签默认收起有计数；筛选激活必有 chips + 清除全部。
5. Viewer：contain 不裁切；页内切换端点 disabled 正确；Esc/空白点击关闭；关闭后焦点归还触发 tile、滚动位置不变；背景不可交互；伙伴 Presence 退后。
6. 六态齐全且互不伪装（空库/搜索空/失败/单图失败/加载骨架/默认）。
7. 无硬编码色值；动效仅 UI 通道；reduced-motion 下无动画；断点仅 480/768/1024 字面量。
8. 每页 16（≤20）；首屏 1 张 eager 其余 lazy；无 originalUrl 铺列表。
9. PictureList / Space / Admin / Shell / Landing 零连带变更；`npm test` / lint / build / 相关 e2e 全绿。
