# 第一季度出口条件验收清单（2026-08—2026-10）

> 日期：2026-08-14
>
> 依据：三年规划第 5 节"第一季度出口条件"。本文是人工验收签字单，逐项打勾后才认为 Q1 完成。

## 出口条件

1. **新用户能在 10 分钟内完成第一次可信喂养**
   - [ ] 新账号注册 → 登录 → 创建私有空间 → 上传图片 → 唤醒伙伴 → 喂养，全流程 ≤ 10 分钟；
   - [ ] 页面每个等待态都有明确反馈，失败都有可执行的恢复动作（重试/换图/创建空间）。

2. **用户能看懂成长原因和图片来源**
   - [ ] 成长档案每条记录展示：来源图片链接、事件类型、经验/性格/技能变化、营养来源标签（演示/元数据/视觉/降级）；
   - [ ] 情绪面板摘要来自服务端，页面不自行解释数值；
   - [ ] 记忆展示来源图片与置信度，纠正后仍可看到最初候选（originalContent 语义）。

3. **重复请求不重复成长，撤权后不继续读取图片**
   - [ ] 同幂等键重放：经验/性格/技能/情绪/关系/记忆候选都不重复产生；
   - [ ] 重复图片第二次喂养只获得熟悉感；
   - [ ] 撤销图片权限（或删除图片）后：新喂养被拒、记忆列表对应记忆变为"来源不可用"、
         记忆转移操作被拒、旧幂等键回放不返回历史结果。

4. **生产环境无明文 Token、原始模型响应或图片 Data URL 落库/入日志**
   - [ ] 按[生产安全审计清单](2026-08-14-production-security-release-checklist.md)第 2 节逐项通过；
   - [ ] `companion_memory.content/originalContent` 抽查：只来自视觉独白或 Demo 固定文案。
