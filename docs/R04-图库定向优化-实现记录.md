## 已实施

1. 保留桌面 `auto-fill / minmax(280px, 1fr)`、24px 间距、4:3 / cover、每页 12 张；保留原手机列策略和 16px 间距，不强迫手机两列。画框显式建立块盒，图片绝对定位，避免图片天然尺寸参与 Grid 行高。
2. 名称、作者、完整日期、最多 3 个标签仍在原底部渐变内常驻。保留 16px 名称、12px / 0.85 透明度元信息和原遮罩，不下移、不隐藏、不缩成省略元信息。
3. 保留 `translate(-2px,-2px)`、`6px 6px 0 var(--black)` 和 `scale(1.05)`。卡片改用真实 RouterLink，键盘焦点可见；触控不依赖 hover，reduce 下去掉位移和缩放、保留静态反馈。点击仍直接去 `/picture/:id`。
4. 搜索图标 / 轻边框输入壳、48px 高搜索与筛选控件、10px 圆角、空间不足换行；搜索按钮与 Enter 都提交。所有返回标签常驻，选中有勾选文字与 `aria-pressed`；新增清除筛选和已提交条件摘要，摘要不随未提交的输入假装更新结果。
5. 区分加载、空库、筛选无结果、列表失败。12 个静态 4:3 加载框不加入无必要动画；失败可重试并清除陈旧总数；分类 / 标签失败不阻塞图片，单独重试。单张预览失败仍保留画框、信息和详情入口。
6. 保留前后页、页数 / 总数、页码输入 + Enter / GO。手机恢复跳页；非法页码归 1、取整数、越界夹到末页；失效深链页按实际总页数重查。
7. 列表请求做本地序号隔离：晚到的旧请求不能覆盖新结果 / 错误 / loading；离开页面后忽略响应。未改变 API 或业务状态模型。

### 手机 GO 的实测修正

使用 diagnosing-bugs 的先复现再定位流程，浏览器用例复现：页码输入失焦后，现有 Shell 底栏恢复，mousedown 命中 GO，而 mouseup 落到底栏，表单没有 submit，且未发出下一页请求。仅在 Gallery 跳页输入聚焦时按 `scroll-margin` 留出底栏空间；没有拦截原生点击、没有修改 Shell。修正后同一用例确认 Enter 到第 8 页、GO 到第 10 页、边界与非法页码均通过。临时事件探针已删除。
