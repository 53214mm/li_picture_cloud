# Observation authorization continuity

Same-account navigation changes the current material epoch rather than revoking the original finite grant. Unsupported or sensitive pages and navigation overlays temporarily suspend observation; returning to a supported page resumes the existing cadence without opening a new session, replenishing balance, an immediate catch-up request, or overlapping calls. Manual pause, account/logout, actual chat, hidden background, expiry, receiver changes and exhaustion still stop the round.

An already dispatched observation drains in the existing single-flight slot. Its validated remaining balance and backoff are reconciled only for the current grant; its stale body and trace are discarded. Prepare/capture results for an old material epoch never dispatch a model. Epoch checks also reject an ABA route sequence. Accepted speech and topic history survive navigation.

Page, visible picture identities and content versions remain dependencies. Rect positions alone no longer identify content: the authorized original raster is reflowed into the fixed region and is not a screenshot of those rects. Visible membership and versions are rechecked before capture and acceptance. Hidden CSS elements remain excluded.

Prepare failures, capture failures and stale attempts receive local stage records. They distinguish definitely not sent from dispatch unknown; they do not fabricate a model response, raw trace, fee, or retry. Transport/model terminal failures do not automatically retry paid requests. A local canvas failure skips that turn while preserving the grant; it cannot bypass an existing server preview digest. A server unsupported-format skip with no preview permits the existing legal text request and sends no visual pixels.

Read-only local format metadata found 233 pictures, zero declared SVG and zero original SVG, 120 declared WebP and 23 JPEG/PNG originals. These aggregate counts do not establish which asset produced the user's unsupported-format message or the two SVG strings. Strict original-format and pixel authorization remain unchanged.

Verification uses deterministic unit tests and a fresh Edge context whose API/provider requests are intercepted. It covers idle successful text, unsupported visual format, no interaction geometry shifts, stage records, routing/ABA/late output, manual/account/chat/background/expiry/budget boundaries, safe real-raster pixel comparison and secret-field exclusion. No real model is invoked. The eighth patch is frontend-only; prior backend verification is historical evidence.
