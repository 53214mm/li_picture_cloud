## 自动化覆盖

- `responsiveFoundation.test.mjs`：断点、44px 触控基线、焦点、安全区与减少动态效果。
- `navigation.test.mjs`：访客、普通用户和管理员入口，以及移动抽屉可访问属性。
- `responsiveViews.test.mjs`：公开页面、图片工作流、空间/AI、后台表格和分析图表的移动布局契约。
- `npm test`、`npm run lint`、`npm run build`、`npm run check:bundle`：功能回归、静态检查、生产构建与体积门槛。

## 浏览器走查记录

- 公开路由已在 360、390、430、768、1024px 五档宽度检查，无页面级横向溢出。
- 360px 与 768px 导航抽屉可打开，打开后焦点进入关闭按钮并锁定页面滚动；按 Esc 后关闭、恢复滚动并将焦点还给菜单按钮。
- 断点实测：360px 与 768px 显示分组抽屉菜单；1024px 恢复桌面导航。
